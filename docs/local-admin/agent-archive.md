# Agent 会话档案

R2已在临时新构建的日常后台完成实测：从实际已加载主人私聊快捷读取人物和共享参数，实际保存目标准确，取消放弃保留草稿，确认重读生效，同号群保持。结束已恢复原程序及测试配置，使用快捷按钮仍需运行包含R2的新构建；范围见[本轮实测](self-test.md#r1-r4-实机测试进度)。

页面“从哪里开始”可展开查看读取范围、进入人物/参数、核对记忆与任务的顺序，并通过页内链接定位已有入口。帮助不会调用模型或写配置；完整操作顺序见[使用指南](user-guide.md)。

## 快捷进入会话设置

运行包含 R2 的新构建，登录后台并在“Agent 会话”读取目标机器人及群/私聊档案。已加载范围下提供“设置此会话人物”和“设置此会话 AI 参数”：点击进入现有 AI 页面并读取对应表单，后续按原保存流程操作，快捷入口本身只读。

入口绑定已成功加载的范围，不取尚未提交的输入。未加载、读取中或范围被更改后按钮不可用，重新读取后启用。切换页面会按原规则清除档案展示；返回时须重读，不保留时间线分页。人物覆盖按机器人隔离，AI 会话参数由本实例各机器人共享；不会因快捷跳转改变配置作用范围。

草稿确认、保存步骤与失败处理分别见[会话人物](conversation-persona.md)及[会话参数](ai-conversations.md)。不会新建 API、写配置、调用模型或发送 QQ 消息；没有新增 QQ 角色权限。日常服务是否部署以当次[自测](self-test.md)结果为准。

状态：M1 已于 2026-10-16 部署到日常程序。使用包含本功能的新构建启动 ZeroBot 后，登录本机后台，在侧栏进入“Agent 会话”。访问权限属于后台密码持有者，与 QQ 角色分别管理。

## 查看会话与时间线

1. 选择已连接机器人。列表只包含当前 OneBot 已连接账号；账号离线时不能手填机器人编号查库，连接后再刷新。
2. 点击会话列表中的群或私聊按钮，或填写会话类型、群号/私聊用户 QQ 并点击“读取档案”。群和同号私聊彼此隔离。
3. 页面显示已加载范围，按新到旧展示序号、类型、时间和脱敏 JSON 正文。动作尝试不等于动作成功，平台回执也不代表 QQ 客户端收到或已读。
4. 默认查看最近上下文重置之后的记录；勾选“包含重置前记录”并重新读取可看归档，查看不会将旧记录重新送入模型。
5. 时间线每页 50 条，下一页沿首次读取的固定快照继续。新消息通过“重新读取时间线”进入新快照；游标 15 分钟过期，退出或重启后台后也需重新读取。

会话列表每页最多 50 个，按内部编号排序，私聊可能排在群之前。“下一页会话”继续读取。没有档案文件、没有记录和读取失败分别提示。读取不创建 Agent、数据库或会话，不调用模型、图片描述或 OneBot 动作。

## 按来源序号定位档案

运行包含本功能的新构建，登录本机后台，在“Agent 会话”读取已连接机器人的目标群或私聊档案。在“按来源序号定位档案”填写引用中的档案来源序号，点击“定位单条档案”，也可在输入框按 Enter。序号为正整数字符串，最大 9223372036854775807；它不是 QQ 消息编号、任务编号、记忆编号或修订号，不按正文或时间猜测来源。

定位始终使用当前已加载的机器人、群/私聊和“包含重置前记录”模式。页面显示实际核对范围及序号；机器人、会话或重置选项变更后，须重新读取档案再定位。搜索中的关键词、发言者、时间、事件类型及 before 条件不限制本次单条读取，可定位当前时间线页或搜索结果之外的已保存记录。默认仍排除最近重置前记录，需明确勾选并重新读取才能核对旧档案；读取不会将旧内容装回模型。

结果单独显示序号、记录类型、保存时间及脱敏纯文本，支持事件、动作尝试、动作响应、任务结束和重置等已保存记录。定位不修改原时间线、搜索条件、搜索继续位置、分页或未提交的搜索草稿；定位读取失败时也保留这些内容，不自动重试。读取按请求时的存储和重置边界核对，独立于时间线原快照；未找到、档案不可用及读取失败分别提示，不能用先前片段代替本次核对成功。

单条正文最多 8,000 UTF-8 字节，超过 64 KiB 的异常正文仅返回占位，截断或占位均有提示。正文不执行 HTML、不加载附件，动作尝试或成功回执不证明平台客户端收到消息，找到来源也不证明引用结论正确。

重新搜索、继续搜索、读取或翻页时间线、刷新账号/会话、切换范围、离开或退出时，清空定位结果及输入；迟到响应不回填。权限沿用后台登录、已连接机器人及当前会话范围。复用 `GET /api/agent/history` 的 seq/archived 参数及原认证、no-store、并发和 3 秒期限，不新增接口、配置或存储结构，不调用模型/OneBot，也不占 Agent 任务的三次查询额度。真实环境使用体验待验收。

## 文本搜索

### 按事件类型搜索

登录后台，在“Agent 会话”读取已连接机器人目标群或私聊后，在搜索表单选择“事件类型”：聊天消息、通知或请求，再点击“搜索”。选择具体类型后可留空关键词，也可和原发言者、保存时间、来源序号及重置选项组合；仅选择“不限类型”时，仍须关键词、发言者或时间范围。权限沿用后台登录用户，不新增 QQ 权限或模型调用。

类型按保存事件顶层 post_type=message/notice/request 匹配。工具“动作尝试”的 kind=request 不算事件请求，正文或嵌套字段提及类型也不算；旧元数据不明确时跳过并提示覆盖不完整。不采集或推断未保存的事件，通知/请求的作者不按 sender 推断，发言者筛选仍仅适用于聊天消息。

结果状态显示本次类型；“继续搜索更早记录”及“查此条之前”保留该批已应用条件并回填，忽略下拉框和输入草稿。原文及前后事件核对不继承类型，邻居可能是其他类型。返回时间线、切换会话、离开或退出会取消条件，迟到响应不回填。

POST /api/agent/history/search 新增可选字符串 eventType，省略或空串不限，非空仅接受 message/notice/request；响应 eventType 表示已应用条件，不限时省略。GET 时间线、单条来源、前后事件和会话列表不接受该搜索参数。仍使用原认证、CSRF、no-store、频率及有界扫描/片段预算，不增加接口或数据库结构。
### 按发言者搜索

登录后台，在“Agent 会话”读取已连接机器人的群或私聊，在“发言者 QQ（仅消息事件，可选）”填写正整数账号，再点击“搜索”。指定发言者后，关键词可留空，按来源序号从新到旧查看该账号的消息；也可输入关键词进一步筛选。未指定时间范围或事件类型时，发言者和关键词不能同时为空。结果状态显示已应用的发言者，数字作为字符串传输，不通过昵称查号，也不联网确认账号存在。权限仍属于后台登录用户，不新增 QQ 权限。

筛选只匹配 kind=event、正文 post_type=message 且顶层 user_id 与所填账号相同的已保存记录。正文提及、昵称、sender 内嵌字段、动作尝试/响应、通知及其他事件类型不作为发言依据。顶层 ID 可为精确正整数 JSON 数字或规范十进制字符串，缺失、无效或无法确认的旧字段跳过并标明覆盖不完整；不自动修复旧档案，不将未知来源归给某人。

可与保存时间、来源序号及重置选项组合。点击“查此条之前”或“继续搜索更早记录”保留该批已加载的发言者与其他条件，未应用的输入草稿不会改变目标；继续查询不是冻结快照。清空后重新搜索取消筛选；返回时间线、切换会话、离开或退出时清空。原文及前后事件核对不重新应用发言者、时间或关键词，邻居可能由其他账号发言；应结合中心与具体事件判断，不能将整个上下文归给被搜索账号。

仍受最近 5,000 条/4 MiB 扫描、20 条/16 KiB 返回及并发/频率/超时限制。非匹配发言者也计入扫描预算，达到上限可能零结果但仍可手动继续；未知字段造成的 partial 不等于还有下一批，未找到也不证明全部历史不存在。默认排除重置前档案，后台显式勾选归档后才扩大到所选会话的重置前范围，Agent 自身检索不允许此选项。

接口 `POST /api/agent/history/search` 新增可选字符串 sender，省略或空串不限，其他值须为正整数 int64 的规范十进制字符串；数字、null、布尔或无效字符串拒绝。GET 档案、单条与列表接口不接受 sender。响应仅在已应用时返回同名字符串字段，它表示查询条件，不证明命中、账号身份或消息真实性。查询只读，不调用模型、识图或 OneBot，不占 Agent 任务额度。使用新构建启动后生效，无新增配置；

搜索接口成功响应新增 searchMore 和可选字符串 nextBefore，用于指明仍可继续的来源边界；它按实际处理进度计算，空结果也可能存在继续位置。partial 也可能仅表示片段截断或跳过记录，不能据此推断还有下一批。页面提供“继续搜索更早记录”和原有“查此条之前”；Agent 也可使用该回执继续查询，见[检索进度说明](agent-memory.md#按实际扫描进度继续检索)。

### 人工核对前后事件

登录后台，在“Agent 会话”读取已连接机器人的目标群或私聊，保持“包含重置前记录”未勾选，再搜索关键词。事件类型的结果提供“相邻事件范围（每侧最多）”及“查看前后事件”，默认每侧最多一条，可选择两条或三条。点击后在原搜索片段下展示中心与相邻事件，并标明中心、序号与保存时间。按来源序号倒序排列；相邻是同一会话的相邻已保存事件，不等于连续 QQ 消息，动作尝试和响应不会作为邻居。只有中心存在才展示邻居；没有邻居时仍可显示中心。

展开固定使用该批已加载的机器人、会话及来源序号，输入草稿不会改换目标；不重新应用关键词、发言者、日期或 before 筛选，邻居可能由其他账号发言或处于原搜索时间窗外。读取按当前存储与最近重置边界重新核对，期间重置或记录缺失时会提示未找到中心；文件不可用、读取失败和回执不符分别提示，不能将旧片段当成新读取成功。点击“收起前后事件”清除展开内容，再展开会重新请求。重新搜索、切换会话、返回时间线、离开页面或退出都会清理内容，迟到响应不能回填。

中心最多 8,000 UTF-8 字节，邻居每条最多 2,000 字节，正文合计最多 16 KiB；超出 64 KiB 的单条仅返回占位，截断或占位会提示不完整。正文只显示为纯文本，不执行 HTML 或加载附件。“包含重置前记录”模式及工具类型结果不提供此按钮；如要检查重置前或工具记录，仍可使用“查看较长原文”。

权限沿用后台登录且机器人须当前连接，只读、不调用模型、识图或 OneBot，不占 Agent 任务查询额度；并发与 3 秒超时沿用档案接口。新构建启动后生效，无新增配置。接口 `GET /api/agent/history` 可与单一正整数字符串 seq 组合可选 context=0～3，0 为当前范围精确事件，1～3 为前后各最多该数量，最多 7 条/合计 16 KiB。不能用于列表、搜索、分页或 archived=true；不带 context 的既有单条读取方式保持。半径大于 0 时响应含 anchorSeq/context 请求信息，不能单凭元数据判断中心存在，需在 entries 中核对。真实 QQ 使用效果待验收。

### 选择前后事件范围

运行新构建，登录后台，在“Agent 会话”读取已连接机器人目标群或私聊的当前档案，保持“包含重置前记录”未勾选，并进行搜索。在事件结果下选择“相邻事件范围（每侧最多）”：1 条、2 条或 3 条，再点击“查看前后事件”。默认 1 条；每条结果各自保留本次选择，不会改变其他条目或搜索条件。

更改范围立即清除该条原先展开的前后内容并恢复读取按钮，不自动发请求；再次点击才按新范围读取。收起后仍保留该条选择，重新展开会重新请求。重新搜索、读取时间线、切换会话、离开或退出会清除旧条目，新结果默认恢复 1 条。读取在途时范围选择暂时禁用，原请求检查和迟到清理保持。

范围始终绑定已加载的机器人、会话和该条来源序号，输入中的账号、会话或搜索草稿不会改变目标。邻居按来源序号倒序显示，不重新应用关键词、发言者、保存时间或事件类型条件，也不会读取最近重置前记录或将工具记录当作邻居。中心不存在时不展示邻居，范围变化不表示档案内容曾经完整覆盖 QQ 原始聊天。

最多展示中心加每侧所选数量：1/2/3 对应最多 3/5/7 条。中心最多 8,000、相邻各最多 2,000 UTF-8 字节，合计仍为 16 KiB；选 3 条时可能因总容量只返回部分邻居，实际记录较少也会少于所选数量。页面回执核对所选范围、中心及顺序，并显示容量或截断提示。正文沿用纯文本，不加载附件。

沿用原后台登录、已连接机器人和会话范围，不调用模型/OneBot，也不消耗 Agent 三次查询额度。复用既有 GET /api/agent/history 的 seq/context，不增加接口、存储结构或模型动作。包含重置前记录、时间线普通浏览及工具结果保持原文入口；它们不显示此范围选择。真实环境体验待验收。

### 按实际进度继续搜索

在“Agent 会话”读取目标会话后搜索关键词。若本次还有可用继续位置，状态文字显示下一次的来源边界，并出现“继续搜索更早记录”。即使当前窗口返回零条也可出现；点击后按服务端实际扫描位置继续，使用该批已应用的机器人、群/私聊、重置选项、关键词及时间范围，不采用尚未提交的输入草稿。新结果替换上一批，不累加显示；每次须手动点击，无自动请求或重试。

继续位置必须是有效正整数字符串，并严格早于当前已应用的 before 边界（如有）。回执缺失、无效或不再前进时不提供继续按钮；仅片段截断、异常时间或超大正文造成的 partial 不等于还有下一批，页面会提示没有可用继续位置。此时无结果仍不能作为全部历史不存在的证明。

“查此条之前”按所点匹配项序号重新查询；“继续搜索更早记录”按已处理窗口继续，可能跨过已经检查的未命中记录。二者都会保留已应用条件。请求开始后清除旧继续入口，失败后须重新搜索；切换会话、读取时间线、离开页面或退出会清除继续位置，迟到响应不能恢复旧入口。无效表单草稿不会替换先前成功结果及其继续条件。

访问权限仍为已登录后台用户，机器人须当前已连接，只读档案、不调用模型或 OneBot。每次继续受原 5,000 条/4 MiB 扫描、20 条/16 KiB 返回、并发、频率及超时限制，按当前存储与重置状态独立读取，不是固定快照搜索分页。后台手动查询不占 Agent 任务三次额度；模型侧继续仍占共享额度。使用包含本功能的新构建即可，无新增配置开关。

### 按档案保存时间搜索

读取会话后，可填写“开始时间”或“结束时间”，直接点击“搜索”，关键词和发言者均可留空，按来源序号从新到旧回顾该时间范围的档案。也可组合关键词和发言者进一步筛选；三类条件至少提供一项。两个时间均可留空，开始时间包含边界，结束时间不含边界；例如要查某一天，填写当天 00:00 到次日 00:00。两端都填写时，开始须早于结束。时间输入使用浏览器所在电脑的本机时区，提交时转换为 UTC，结果状态显示实际应用的 UTC 范围；浏览器对夏令时重复或不存在时刻的解释沿用本机日期规则。

未指定发言者时，后台仍可返回事件、动作尝试及响应等原有档案类型，回顾时应区分用户发言和工具记录。只填时间也可使用“继续搜索更早记录”和“查此条之前”，二者保留已加载的空关键词和时间条件，不采用未提交的输入草稿；不自动遍历全部历史。

筛选依据是机器人写入档案的保存时间，不是 QQ 消息自带时间，也不是模型动作的实际执行时刻。服务器时钟调整可能影响顺序，时间线仍按来源序号倒序。时间筛选在原有最近 5,000 条及 4 MiB 有界扫描内进行，范围外记录仍计入扫描预算；选择很早的日期不会跳过这两项上限，较旧匹配可能需要结合来源序号边界继续查。无法解析的旧时间不会猜测或匹配，页面提示覆盖不完整。

“查此条之前”保留该批结果的关键词、时间条件和已加载会话，不使用后续尚未提交的草稿。清空某一端再搜索即可取消该端；重新读取时间线、切换会话、离开页面或退出会清除时间条件。展开原文仍按精确来源和当前重置范围读取，不重新执行关键词或时间筛选。后台条件不改变时间线分页、会话列表或模型的当前查询；Agent 可独立传入时间范围，见[模型历史检索](agent-memory.md#按保存时间检索历史)。

权限仍为后台登录用户且机器人须当前已连接，查询只读，不创建 Agent、不调用模型或 OneBot。功能随新构建生效，无新增配置开关。接口 POST /api/agent/history/search 新增可选字符串 from/until，接受带时区的 RFC3339 时间（可含纳秒），服务端按实际时刻比较；省略或空串不限对应端。参数不能用于 GET 时间线、会话列表或单条读取，也不能和搜索游标、seq 混用。入口沿用 CSRF、并发、频率和超时限制。

### 按来源序号继续搜索

可在“仅查此来源序号之前（可选）”填写正整数序号后搜索；例如填写 23，只查序号小于 23 的记录，不包含该条。留空从最新记录查起。结果中的“查此条之前”会沿用该批结果的关键词、时间条件与已加载会话，以该条序号重新搜索，不使用尚未提交的关键词草稿。结果状态显示实际使用的序号边界；序号不等同时间，也不要求边界记录仍存在。

每次都是独立的有界查询，仍遵守已加载的重置选项、5,000 条及 4 MiB 扫描上限、结果数量和频率限制；没有结果不能推断所有历史都不存在。它不是固定快照分页，不能保证覆盖期间变化的全部档案。返回时间线、切换范围或退出时清除边界输入。接口 `POST /api/agent/history/search` 支持可选正整数字符串 `before`，省略或空字符串表示不限定；不可与分页游标或单条序号组合，GET 档案接口不接受该参数。

搜索完成后，每条结果可点击“查看较长原文”，在原片段下展开同一序号的脱敏正文；点击“收起原文”清空展开内容，保留搜索片段。重新展开会再次读取。展开固定使用搜索时已加载的机器人、会话和重置选项，未提交的输入不会改变目标，也不会自动包含重置前记录；搜索关键词及结果保持原状。仍需后台登录且机器人当前已连接，不调用模型或 OneBot。

展开每条最多 8,000 UTF-8 字节，超过 64 KiB 的正文仅显示占位；仍被截断时明确提示，不宣称完整原文。它按当前存储状态重新读取，不冻结为搜索时快照；若期间发生上下文重置、文件变化或记录缺失，会提示当前范围未找到或档案不可用。读取错误与未找到分别显示，旧搜索片段保留供辨认，不当作读取成功。重新搜索、读取时间线、切换会话或退出时清除展开内容，迟到响应不能回填旧内容。

成功读取会话后，输入 1～128 个字符，或指定发言者/时间范围后将关键词留空，点击“搜索”。有关键词时为区分大小写的字面子串匹配，针对脱敏后的 JSON 文本，不是语义检索；采用点击时的新快照，沿用已加载范围和重置选项。关键词经请求体传输，不进入 URL。

单次最多检查最近 5,000 条及 4 MiB 正文，最多返回 20 个片段，每片段最多 2,000 UTF-8 字节、合计最多 16 KiB。结果显示检查条数与是否覆盖不完整。无结果只表示已检查内容没有匹配，不代表全部历史不存在。搜索不分页，点击“重新读取时间线”回到浏览。

超过 64 KiB 的单条正文不读取，时间线显示占位，搜索标记覆盖不完整；普通时间线每条最多显示 8,000 字节。截断不修改原记录。正文作为纯文本显示，不执行 HTML，不自动加载图片或附件。

查询超时为 3 秒，同时最多处理 2 个档案请求，搜索间隔至少 250 毫秒；繁忙或超时可稍后重试。失败清除本次结果并禁用后续翻页，不自动重试，也不把存储故障显示成空档案。

## 数据与生效范围

长期记忆及历史版本可通过“查看来源”读取同一范围的单条档案摘要，使用步骤见[记忆管理](agent-memory.md)。接口 `GET /api/agent/history` 可附加正整数 `seq`，须同时指定机器人和会话，不能与游标、列表或搜索组合；默认遵守重置边界，记忆来源页面显式传入 `archived=true`。精确查询仍执行脱敏、正文上限和只读限制，不提供无限制完整正文。

读取现有 `data/aichat/history/<机器人QQ>.sqlite`，不迁移、不重置、不修改档案。切换范围、离开页面或退出登录会清除页面档案和搜索内容，不在浏览器本地存储保存正文。隐藏当前配置的模型密钥和密钥设置命令；旧档案仍受原有写入脱敏范围限制。

M1 提供后台浏览和搜索，M2 已补充 [Agent 检索和记忆管理](agent-memory.md)，M3 提供[任务状态与停止](agent-tasks.md)，实际使用须运行相应新构建；不新增 QQ 指令。配置备份不包含档案、长期记忆或任务，备份方式见[Agent 档案](agent-history-2026-10-03.md)。
