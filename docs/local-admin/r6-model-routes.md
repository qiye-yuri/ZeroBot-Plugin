# R6：GPT、群总结独立模型入口

本批在已验收[R5独立参数](r5-model-parameters.md)基础上完成，R5对应[PR #9](https://github.com/qiye-yuri/ZeroBot-Plugin/pull/9)，尚未合并。R6独立分支为 `codex/gpt-summary-model-routes`；上传不代表已部署。R7会话配置核对仍待后续开发，N3联网搜索保持暂缓。

## 使用与兼容

登录后台进入“AI 设置”，读取命名模型配置。聊天仍必选，GPT和群总结分别新增下拉框，默认“继承聊天模型”，也可选择已有配置；保存后新请求生效，无需重启。模型可被多个入口引用，共用其R5独立参数；需要不同参数就新增配置。

| 入口 | 空引用 | 自定义引用 |
| --- | --- | --- |
| 聊天 | 保存拒绝 | 普通聊天及其回退使用所选配置 |
| GPT | 继承聊天配置与参数 | `/gpt`使用所选配置与参数 |
| 群总结 | 继承聊天配置与参数 | `群聊总结`使用所选配置与参数 |
| Agent、识图 | 保持原停用语义 | 保持各自独立选择 |

页面显示当前选择或继承来源。删除模型前需处理五个入口的显式引用；引用不存在时提示重新选择，保存和运行均不把坏引用改成继承。旧模式继续使用原聊天字段，旧三入口JSON无需迁移，读取不写库。详见[命名模型操作](named-models.md)。

GPT和群总结仍共用LLM会话温度及每群/私聊30秒额度，沿用原插件开关、群管理员权限、提示词、引用消息和长回复处理。只替换模型入口，不增加停用GPT开关，不添加新的费用或统计类别；实际请求继续计入“GPT／群总结”。

## 诊断与脚本

“AI 配置检查”分别显示五个入口的基础字段状态。手动诊断增加GPT和群总结按钮，使用已保存修订，只发固定短文字，不读取群历史或执行群总结，不调用QQ；输出长度仍为128，TopP和推理设置跟随入口。四个诊断按钮共用现有单请求门控，结果及草稿行为保持，见[手动模型测试](model-probe.md)。

R1脚本预检列出五类入口，原七项默认用例保持；新增 `summary` 需显式选择。新版脚本需配套R6构建，例如先构建后执行 `go run scripts/test-real-model.go -run -binary-name zerobot-r6-final.exe -cases gpt,summary`。`-run`调用实际提供商，可能计费；群总结只使用隔离OneBot提供的合成群信息与历史，不读取真实群聊。详见[真实模型测试](real-model-test.md)。

## 实现与验收

| 工作包 | 实现 |
| --- | --- |
| R6-01 | 纯路由解析增加可选GPT/群总结引用；一次配置读取固定五入口及参数，LLM从快照选择，保留全局继承来源 |
| R6-02 | 原命名模型表单增加下拉、来源及引用删除检查；一次修订/备份保存完整列表和路由 |
| R6-03 | GPT和群总结分别绑定入口，保留原权限、额度、提示词、温度和统计 |
| R6-04 | 五入口基础状态、四个显式诊断按钮及原协议适配复用，无新客户端或自动重试 |
| R6-05 | 五个不同模拟地址/模型/凭据/参数的最终程序测试，另测继承、删除、重启、旧JSON和备份恢复 |

统一入口为 `pwsh -File scripts/test-agent.ps1 -OutputName zerobot-r6-final.exe`；验收结果见[自测记录](self-test.md#r6-gpt群总结独立入口验收)。模拟服务、真实提供商和真实QQ分别记录，互不替代。
