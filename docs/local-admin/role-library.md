# 角色库与每日抽取

P095 `wife`统一内置角色、自定义角色及猜角色游戏，P071 `nwife`不再独立注册。原有群图片及“所有人可添加”权限继续沿用，无需重新上传。P075群成员配对仍是独立插件。

| 命令 | 作用与权限 |
| --- | --- |
| `抽老婆` | 群内优先从本群自定义库每日抽取；没有自定义角色时使用内置库。私聊使用内置库 |
| `抽内置老婆` | 明确使用内置角色库 |
| `抽wife` | 仅抽本群自定义库，兼容原入口；空库返回提示 |
| `添加wife角色名字`并附图片 | 在同一条群消息添加或覆盖同名角色；默认群管理员或主人可用 |
| `删除wife角色名字` | 删除当前群该角色；群管理员或主人可用 |
| `让所有人均可添加wife` | 主人在当前群开放成员上传 |
| `不让所有人均可添加wife` | 主人在当前群关闭成员上传；不影响管理员 |
| `猜老婆` | 从内置角色库出题；按提示回答角色名，发送`跳过`结束 |

服务列表和后台只展示`wife`。`/禁用 wife`同时关闭内置抽取、自定义角色管理及猜题；`/启用 wife`恢复。原`nwife`开关不再单独生效，群沉默和权限控制仍适用。游戏进行时同会话内置抽取可能提示忙碌。

`抽老婆`、`抽内置老婆`、`猜老婆`及游戏中的`跳过`允许首尾空格和末尾句号、感叹号，例如`抽内置老婆。`、`猜老婆。`、`跳过。`。这些命令由角色插件直接处理，不需要经过AI聊天；添加/删除命令中的角色名字仍按原规则处理。

猜题进行时，当前私聊或当前群的有效答题消息与“跳过”由游戏优先处理，不再同时交给AI聊天。游戏忽略机器人自身消息，结束后恢复普通消息处理。

自定义图片仍保存在`data/nwife/`下按群分隔的目录，原上传权限仍在旧命名空间读取；内置素材保存在`data/Wife/`。本地已有内置素材直接使用，缺失时才尝试远程下载，网络或素材缺失仍可能导致内置抽取或猜题失败。角色库JSON为空时返回明确提示。

自定义每日结果沿用原昵称和日期规则，修改昵称或增删图库后结果可能改变；内置每日结果沿用用户ID和日期规则。自定义上传支持PNG、JPEG、GIF，最大10MiB；失败不会覆盖原图片。角色名不能包含路径、Windows保留名等非法字符，最长80字。更改图片或权限立即生效。

本批删除P011 aiwife、P027 coser、P055 lolicon、P065 nativesetu、P084 setutime，启动注册与用户列表不再展示，旧数据保留。P010本地画图继续暂缓。

测试状态见[插件清单](feature-plugin-inventory.md)与[验收记录](feature-test-results.md)。隔离测试不代表真实QQ已经成功显示图片。


自定义角色验收时使用未存在的专用测试名字：同一条群消息附文字和图片完成添加，再附另一张图片覆盖同名测试角色，检查保存回复；`抽wife` 可能抽中群内其他已有角色，不保证抽到测试名。最后用 `删除wife测试名字` 清理，仅删除本次创建的角色。不要修改已有角色或为测试开放所有人上传。上传/覆盖、网络和图片错误保留旧图、重启保存及删除已有17项隔离验证；真实QQ上传和显示单独验收。

### 猜角色的答题与结束

收到题目后，以“角色名酱”作答，共3次机会；答错前两次会提示剩余次数并降低图片难度，第三次答错结束并揭晓角色。答对或发送“跳过”（支持末尾句号）立即结束。无人作答时，约105秒提醒剩余15秒，约120秒结束并揭晓；计时从题目发出后开始，不因答错重新计时。结束后可再次开局，仍受正常调用频率限制。

跳过后若图片发送失败，备用文字仍明确标为“已跳过猜题”，不再误报猜对；提前结束会停止本局计时器。2026-10-23本地合成素材与合成QQ的18项流程检查通过，包含连续答错、答对、跳过、自然超时、重新开局及结束后10秒静默；完整两分钟的提前结束后静默另由QQ实机确认，不将短时隔离观察视为该项完整验收。
