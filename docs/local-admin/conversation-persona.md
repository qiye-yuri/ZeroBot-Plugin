# Agent 会话人物覆盖

在本机后台 `http://127.0.0.1:3010/` 登录后进入「AI 设置」。此功能需要后台登录权限、已编译 AI 配置插件，以及当前已连接的机器人账号。

需要运行包含 N1 的新构建才能看到入口；源码上传不会自动升级日常服务，升级与备份见[运行维护](operations.md)。

1. 在「人物覆盖的机器人 QQ」填写机器人账号，选择群或私聊，再填群号或私聊用户 QQ，点击「读取会话人物」。
2. 核对表单标题中的机器人与会话。表单显示当前来源；继承模式下人物正文和性别为本次读取到的全局值。
3. 选择「自定义」，填写非空人物设定和性别，点击「备份并保存会话人物」。正文最多 32768 UTF-8 字节，性别最多 256 字节，与全局字段相同；性别为自由文本。
4. 恢复全局人物时，选择「继承全局」并保存。此操作删除当前会话的覆盖，后续新任务跟随全局人物。继承状态下展示的文本仅是读取快照，重新读取可核对最新全局值。
5. 「放弃此表单更改」恢复本次读取/保存的值；切换人物范围前会提示未保存草稿。仅修改范围输入不会改变已加载表单的保存目标。

覆盖按机器人账号和群/私聊分别保存；同号群与私聊、不同机器人互不覆盖。它仅影响新的 Agent 任务，不改变普通聊天、GPT 或群总结的系统提示词，不改变插件开关、触发概率和角色权限，也不会清理档案或长期记忆。

会话人物保存后无需重启；已开始任务固定使用开始时的人物，不在多轮执行中混用新值。全局配置编辑仍沿用原有设置代次机制，进行中任务会在后续检查点停止；重新发起的任务使用新配置。

本表单与全局配置共用数据库修订。若提示配置已变化，重新读取目标范围，核对后再保存；不会自动覆盖其他窗口的新值。保存使用已有控制数据库写前备份，重启后覆盖仍保留。升级前没有覆盖字段的旧配置默认继承全局。主人私聊人物命令继续修改全局值，自定义会话不跟随该值变化。

接口为 `GET /api/ai-persona?botId=12345678&type=group&id=101` 及同路径 `POST`。写入使用读取返回的 `revision`，`mode` 为 `custom` 或 `inherit`，自定义时附 `character`、`sex`；私聊使用 `type=private` 和正数用户 QQ。POST 沿用后台来源及 CSRF 校验。以上账号为示例。
