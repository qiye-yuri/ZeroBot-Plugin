# 已保存搜索密钥诊断（R9）

本批已实现，尚未合并部署；测试和交付状态以[自测](self-test.md)为准。部署包含 R9 的程序并刷新页面后显示入口，无数据迁移。

登录本机后台，在 **AI 设置 → 联网搜索** 读取已连接机器人和群／私聊的搜索设置，也可从会话配置核对使用 R8 快捷入口。读取后点击“测试已保存搜索密钥”。按钮附近会提示：发送一次固定公开查询，可能消耗提供商额度。

诊断仅使用全局已保存的搜索密钥及当前读取的配置修订。未保存的新密钥、模型密钥、聊天内容、QQ 身份、历史和记忆不参与请求。固定查询为“Go 编程语言 官方文档”，请求5条、不抓取网页全文。即使全局或会话搜索关闭，也可显式诊断已保存密钥；诊断不会开启业务搜索、保存配置或改变角色权限。

缺少已保存密钥时按钮不可用；先显式保存后再测试。版本冲突时重新读取再决定是否测试。模型诊断与搜索诊断共用一个在途名额，不排队、不自动重试。搜索最多等待10秒，期间重复点击不会重复发起。

结果只展示分类、测试时间、耗时、HTTP状态（实际收到时）、合法结果数和配置版本。成功仅代表本次基础请求通过；空结果表示调用完成但没有匹配，不代表认证失败。HTTP错误保留状态码；网络、无效响应和超过256 KiB分别提示，不展示提供商正文、标题、摘要、链接或密钥。

结果仅保留在当前 AI 页面，重新读取或保存后修订不同会标为历史结果；不会自动轮询另一页面的修改。离开或退出清除结果并忽略迟到响应，但不能撤销已经产生的提供商费用。保存、导航、配置核对不会自动测试。

诊断不消耗 Agent 任务的两次搜索额度，不写入模型业务统计、任务、档案、记忆或配置备份。正常业务启用条件仍见[联网搜索](web-search.md)；模型测试见[模型诊断](model-probe.md)。
