# FTB首次发送期间保持忙碌

本批修复下载校验完成后、QQ文件仍在发送时过早释放任务状态的问题。入口仍为原FTB下载命令，无新开关或后台页面。

自动发送开启时，下载、校验和首次QQ文件发送连续占用现有任务状态，直到发送接口返回或超时。期间FTB工具状态显示忙碌，新的查询/下载/重发和配置保存被拒绝；发送结束后恢复可用。未开启自动发送时，下载校验完成即释放状态。

FTB取消继续只处理查询/下载阶段。已进入QQ发送阶段时明确提示不能取消上传，不因下载阶段超时随后到期而把已成功返回的发送误报为下载超时。QQ发送仍使用原有独立等待上限。

使用任务实际开始时读取的发送位置，发送期间配置不能改写；权限、目标选择、文件校验、下载次数和失败后保留文件的规则保持。接口成功仍不等于用户实际收到，网络回执不明后手动重发仍可能重复，本批不承诺跨平台严格一次投递。

部署后生效，无需更改配置。测试和交付见[本批记录](ctb-delivery-lifecycle-acceptance.md)。已取消QQ配合验收不重排。
