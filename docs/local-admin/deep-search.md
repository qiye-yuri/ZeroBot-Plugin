# 深度思考搜索

当前状态：实现与相关合成回归已完成；本批发布范围见[接口整合交付](interface-refactor-delivery.md)。QQ收发未新增验收。

## 入口

`深度搜索 问题`或`深度思考搜索 问题`。群聊需真实@机器人，私聊直接发送。每条命令独立回答，不携带聊天历史、人物设定或QQ身份，不自动续搜，也不继承上一轮搜索网页。

保留原有联网搜索：现有Agent的独立Search API及每任务两次限额不变。本入口使用DeepSeek服务端搜索，两种方式独立，不会失败后互相回退重试。

## 配置

复用联网搜索总开关、会话范围和角色权限。普通聊天采用Chat模型入口，Agent会话采用Agent入口；所选入口需为DeepSeek官方HTTPS地址、OpenAI协议、deepseek-flash和有效模型密钥。请求实际使用该模型密钥，搜索配置的密钥要求仍按既有权限设置执行。

仅声明deepseek_web_search，开启thinking和high思考强度、high内容安全。不向客户端Agent开放本地动作，不自动启用阅读链接或其他新能力。

## 结果与来源

识别服务端多步搜索、打开网页及页内查找结果。只展示最终回答，不展示reasoning_content。来源附录仅收录成功工具结果中的有效HTTP/HTTPS链接；优先使用模型引用中能与这些结果对应的来源，最多展示8项。模型没有可核对引用时明确标为检索来源，不声称逐条论断已经核实。

未获得成功搜索来源、所有搜索失败、HTTP 200错误对象、内容审核拒绝、空回答等情况不展示未经检索支持的答案。部分步骤失败时提示范围不完整；达到输出上限时标记截断。来源链接归属检查不等于事实核验，回答仍需结合原网页判断。

## 耗时与费用

一条命令最多1次模型HTTP请求，不重试；但请求内部可能多次搜索和抓取，不能套用旧搜索的“两次上限”。搜索次数和网页抓取由服务端决定，本版没有金额硬上限。

请求最多等待180秒，响应最大2MiB，问题最多4096字节，最终答案超过10000字时提示缩小范围。max_tokens=2048是每一步输出上限，不是整轮总输出或费用上限；超时/断开不能保证服务端已停止或不计费。

与链接阅读共用请求处理；调用方已有更短超时则沿用更短限制，不跟随HTTP重定向。深度搜索仍保持独立的思考参数、来源核验和配置变化后的结果丢弃规则，无需新增配置。

回答末尾展示服务端返回的输入/输出token，以及计费搜索、抓取、图片搜索次数；缺失字段明确显示未返回，不当作0。现有模型统计记录token，但工具次数尚未进入后台统一费用汇总，不能仅按模型统计推算总费用。


## 验证范围

使用模拟HTTP响应验证权限、模型选择、请求参数、结果解析与失败不重试；不以自动化替代真实QQ验收。
