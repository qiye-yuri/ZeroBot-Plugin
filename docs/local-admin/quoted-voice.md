# 引用群语音转文字或提问

在 QQ 群里回复一条语音，明确 @ 机器人，再输入「转文字」。机器人会将该条语音的转写作为文字消息发回群里。也可以输入「帮我总结一下」或「最后定在哪天？」。提问时会把问题和转写送入当前会话配置的模型，沿用该群的人物设定，单次生成文字回答。此入口只回答当前问题，不运行 Agent 工具。

沿用本群 AI 插件、聊天配置及 @ 响应设置。需要连接端支持 NapCat 的 `get_msg` 和 `fetch_ptt_text`。每次触发只转写一条本群引用的语音，单条转写最多 4000 字。「转文字」无需额外的聊天模型请求。语音未引用、没有 @ 机器人或仅发送语音时不会启动转写。消息已撤回、转写失败或结果为空时会给出提示。

该入口沿用QQ连接端转写；独立ASR是另一个显式命令，不互相自动回退。原聊天数据与测试数据继续隔离；本批仅执行模拟QQ及本地模型验收，真实QQ收发仍单独记录。
