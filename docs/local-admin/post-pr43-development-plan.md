# PR43后的详细开发计划：任务视图排版与可读性

核对日期：2026-10-27（Asia/Shanghai）。基线master `0643513d73581c0967ddaf7f1ba966a381c63e77`。PR #43已完成部署验收及合入，见[最终清单](task-outcome-summary-acceptance.md)。本次仅交付后续设计及配套记录，以下排版尚未实现。

## 1 问题与目标

任务视图已具备筛选、排序、重置、折叠与结果分布。实际验收画面中，三个标签、选择框和重置按钮连续排在同一行，摘要的身份、结果分布、Token小计及缓存信息也呈现为密集长行。功能正确，但扫描和对照信息较费力。下一批先改善现有内容排版，不增加新的统计或操作。

源码依据：index.html中任务控件目前直接连续排列；modelTaskSummaryText已用换行连接四段文字，renderModelTaskView用summary.textContent写入。现有样式未针对这组任务控件及动态摘要提供局部排版规则。以真实浏览器截图和计算样式复核最终效果，不能只因字符串含换行就判定页面已经分行。

目标为标签与控件一一对应、窄屏自然换行、摘要四段清楚分开，并保留原生details/summary的折叠标记和键盘行为。历史预算900000、[其他待验收和暂缓项](remaining-acceptance.md)保持，不扩展到全站视觉重构、其他插件或真实业务测试缺口。

## 2 页面结构与交互契约

入口保持“运行概览 → 模型接口请求 → AI费用风险提示 → 按任务查看用量”，无需额外权限。风险、结果、排序及重置的名称、选项、ID、顺序、默认值、事件和禁用行为不变。

### 筛选工具区

将三个label/select分别包在局部字段容器内，再与重置按钮放进一个任务工具区。标签在各自选择框上方，说明段落与结果列表位于工具区之后；不要把按钮或其他可操作元素移入任务summary。重置按钮保留type=button，不新增form，避免Enter触发额外提交。

宽度充足时三个字段与按钮可同行；空间不足时按源码顺序自然换行。优先使用局部CSS Grid及现有断点，避免根据JavaScript视口宽度计算布局。字段容器min-width:0，选择框width:100%、max-width:100%，用自适应列宽避免固定总宽度。320px视口采用单列，按钮可独占一行；1280px与中间宽度均不得横向溢出。不要只写两个固定断点而遗漏过渡宽度。

选择框沿用现有主题变量和字体，保证暗色/浅色文字、背景、边框可辨。为本区补齐font:inherit、适当内边距和不小于44px的可点击高度；不改全站select样式，不替换原生下拉弹层。保留可见焦点，不能以outline:none隐藏键盘位置。

### 任务摘要与明细

在动态任务summary上明确保留换行，优先局部white-space:pre-line及overflow-wrap:anywhere，让现有四段文本直接呈现为身份、结果分布、Token小计、缓存信息四个逻辑段。不拆成新的数据模型、不重复生成摘要、不改变计算函数。

保留summary的原生display:list-item与折叠标记，不使用flex/grid覆盖summary本身；任务details之间增加适度间距，summary提高到可读字号和行距，沿用主题颜色。不隐藏标识、截断数字或用省略号代替未知/覆盖次数。长匿名标识、模型名和大整数可换行，不能撑宽页面；展开正文也应沿用原有换行规则。

摘要整个可点击区域仍能切换折叠；Tab顺序继续为风险、结果、排序、重置、任务摘要。Enter/空格、同键刷新焦点、展开保持、筛掉后返回收起、离页/退出清理均保持。外层details的标题和其他页面不受局部样式影响。

不能仅断言CSS包含某个属性或字符串带换行。使用浏览器实际计算样式、边界框及文字片段的垂直位置验证排版，再人工查看截图；缩放/换行可能使一个逻辑段占多行，不硬编码总行数或像素高度。CSS行为测试覆盖关键约束即可，不为每个间距写镜像测试。
