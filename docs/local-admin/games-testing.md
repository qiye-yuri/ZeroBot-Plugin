# 钓鱼、群成员配对与塔罗验收

## P058 钓鱼

私聊或允许响应的群可发送 `查看钓鱼规则`、`钓鱼背包`、`当前装备概率明细`、`钓鱼商店`。`进行钓鱼` 会消耗装备耐久并产生物品；新用户可能收到100虚拟币购买鱼竿提示。确认仅接受同一用户在原会话发送的“是/否”，优先于AI聊天消费确认消息，避免其他会话误确认。回复“否”结束本次购买，不应在两分钟后再次发出超时提示。验收先回复“否”，购买、交易、附魔等写入余额和背包的测试先使用隔离账号。

## P075 群成员配对

仅群聊可用。`群老婆列表` 查看当天记录；`娶群友` 从近期群成员候选中随机配对，可能出现未抽中或单身结果。重复请求应沿用当天已有关系。候选为空或仅一个时返回无可用对象提示，不再随机取空列表。结果头像最多等待3秒，头像下载或发送失败时仍返回文字结果；已保存关系不会因头像失败重抽。它会保存当天游戏关系及好感度；不要把游戏配对当作真实关系。

`好感度列表` 可查看记录。重置花名册等管理操作不用于日常验收，权限通过隔离账号验证。

群管理员或机器人主人可在目标群发送 `允许自由恋爱`、`禁止自由恋爱`、`允许牛头人`、`禁止牛头人`，以及 `设置CD为3小时`（按需填写整数小时，默认12小时）。设置立即保存并在重启后保留，只影响该群；两个玩法开关互相独立，修改设置不清空现有配对、好感度或技能冷却记录。普通成员无权修改，私聊不执行这些设置命令。不要为了验收改变日常群设置，权限和保存分支优先用隔离数据测试。

## P088 塔罗

私聊或群可发送 `抽3张小阿卡纳`、`解塔罗牌愚者`、`塔罗牌阵圣三角`。小阿卡纳使用完整56张牌，混合牌阵使用完整78张牌；修复前最后一张未进入随机池。单次多张最多20张，零张或超限应明确提示。

牌面下载与本地缓存影响首次速度；附带问题的解读还依赖AI配置。隔离测试使用合成图片验证逻辑，不能替代真实牌面显示及外部资源验收。

### 钓鱼交易与装备的交互范围

购买/出售的“是/否”、出售所有垃圾确认，以及装备/修复/合成和商店条目的序号选择，只接受发起操作的同一用户在同一会话内回复。私聊发起的交易不能在群内确认，群里发起的操作也不能在另一个群或私聊确认。匹配的回复先交给游戏处理，避免普通AI聊天代答。

序号选择按提示使用“取消”退出，购买/出售确认使用“否”取消。序号选择最长两分钟，交易确认最长一分钟，错误序号不会延长总时限；每一步完成后立即撤销该步监听，后续确认不会被前一步吞掉。取消不会扣除本次交易的余额或物品。装备、修复和合成的成功操作会正常改变游戏进度，不应当作只读查询。

实机检查优先使用购买取消；若余额不足或无货，记录该空状态即可，不必为了测试调整余额。真实装备/消耗/交易尚未全部验收，模拟背包结果不等同真实多人游戏通过。

商店询价只计算价格，不提前消耗半价优惠或累计购买次数；确认成交并成功入包后才更新这些记录。取消、超时或余额不足不消耗该笔交易的优惠。提示中的优惠次数表示本次计划使用的次数，成交后扣除。

### P075 花名册管理边界

仅机器人主人可执行重置，群管理员身份本身不足以授权。`重置花名册`、`重置本群花名册`在群内清理本群；主人可在私聊或群内使用`重置群号花名册`指定目标，例如`重置123456789花名册`。单群重置清除该群关系和技能冷却，保留群设置及好感度，不影响其他群。`重置所有花名册`按既有规则清除全部群关系、设置和冷却，但保留好感度。以上操作即时生效，会删除对应游戏记录。

指定群号必须是有效的正整数，0或超出整数范围的值明确拒绝；私聊省略群号时明确提示需要群聊或指定群号。2026-10-23修复了数字群号入口无法匹配及忽略转换错误的问题，17项合成数据隔离检查通过。日常验收不执行真实重置；QQ仅可复核私聊省略群号、0和超长群号的拒绝提示。隔离结果不标成真实数据重置通过。

2026-10-23：`scripts/test-qqwife-reset.go -settings-boundaries` 新增设置权限、跨群隔离及重启保存检查，与原重置测试合计33项通过。仅使用隔离合成数据；没有修改日常群配置，不代表真实多人互动已验收。

塔罗牌面优先使用可解码的本地缓存；缓存损坏会尝试重新下载，HTTP失败、非图片或超过8MiB的网络响应不会写入缓存。下载成功但本地缓存无法写入时，仍使用本次有效图片，之后请求可能再次下载。2026-10-23以上4种故障恢复场景通过合成图片隔离测试；若远程源不可用且缓存缺失或损坏，仍无法凭空恢复图片。

群配对头像网络响应超过2MiB、状态失败或无法识别为图片时，不作为头像发送。图文发送未确认成功时最多再尝试一次去除图片的文字结果；纯文字失败不循环重试。网络回执丢失仍可能导致用户收到图文和文字两条，不能将重试次数限制理解为QQ端严格仅送达一次。2026-10-23新增8个模拟边界场景及原有回归通过。
