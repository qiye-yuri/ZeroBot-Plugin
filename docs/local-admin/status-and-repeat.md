# 系统自检、默认限速与打断复读

## P009 aifalse

主人或群管理员发送 `自检`、`系统状态`、`检查身体` 或 `启动自检`，返回运行时间、CPU总使用率、内存、磁盘及插件数量图片。私聊需要机器人主人权限。图片使用本地背景和头像占位图，不依赖外网装饰图片；字体仍需本地可用。

主人可发送 `设置默认限速为每10秒5次触发`。间隔支持秒/分钟，转换后范围为1至65535秒；次数为1至65535。成功保存后立即重建默认限速器，已有用户也使用新配置，重启后恢复。只影响接入默认限速器的插件，不限制所有聊天，也不会覆盖插件自定义限速器。

系统自检与后台状态页有部分重复，但本插件还负责默认限速配置的启动加载。

## P107 breakrepeat

同一群连续收到5条相同的非图片消息时，回复“打断复读：”及打乱顺序的原文字。单字符也会明确标注打断，不再显示内部计数前缀。不同群分别计数，换文字重新计数；机器人自身消息不参与。图片不参与计数，包括仅有文件标识、没有公开URL的图片消息。使用 `/启用 breakrepeat`、`/禁用 breakrepeat` 管理现有会话开关，权限沿用插件管理规则。
