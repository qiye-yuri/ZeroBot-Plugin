# 图片插件与首次素材准备

当前保留的本页功能为P088塔罗牌。普通用户可在允许响应、对应插件启用的私聊或群发送：

- `抽塔罗牌`：输出一张牌与说明；`抽3张塔罗牌`可一次抽多张，最多20张。
- `解塔罗牌愚者`：查询该牌正位、逆位含义。
- `塔罗牌阵圣三角`：输出现状、愿望、行动三张牌和文字汇总。
- 抽单张或牌阵后附加问题会另行调用AI解读，需要有效AI配置。无问题时仅查询本地牌义。

合并消息中的生成内容使用机器人身份。所有牌图下载共用8秒等待上限，优先读取本地缓存；缺图时仍返回牌名、牌位和释义，牌阵汇总直接发送文字，不再依赖字体渲染。该上限只针对图片下载，不包含QQ发送和可选AI解读时间。每群独立限流，私聊按用户隔离；过快请求会提示稍后重试。

首次使用可能下载牌面，后续复用缓存；网络失败与本地权限问题应分别排查。代表性图片实机通过不等于所有牌阵、素材和异常分支均已验收，详见[测试结果](feature-test-results.md)。

## 已删除的相关功能

每日运势（含抽签别名及设置底图）、任意文字渲染、抽扑克、浅草寺求签/解签、自定义签包、猪猪、摸鱼日历、支付宝语音、表情合成、煎蛋随机图、文字摸鱼提醒及点歌均已移除。旧数据保留，不再提供对应插件命令；历史修复记录不代表当前仍启用，去留以[插件清单](feature-plugin-inventory.md)和[删除记录](removed-plugins.md)为准。


## 完整图片缓存维护

2026-10-22已补齐78张塔罗正逆位共156张牌图（约95.1 MiB），逐张完整解码通过；机器人实际加载函数在取消网络请求的情况下读取156张全部通过。文件位于`data/Tarot/`，新增缓存立即生效，无需重启。部分上游`.png`文件实际编码为JPEG，应按内容识别，不应仅按扩展名判损坏。

维护时在项目根目录运行（需要Python与Pillow）：

```powershell
python scripts/cache-tarot-images.py
python scripts/cache-tarot-images.py --kind mcfish
```

脚本以现有清单为准，跳过已校验的图片，只补缺失或损坏文件；下载内容完整验证后才替换，旧损坏文件留在本机`.local/`备份。下载失败会返回非零退出码并列入本机结果清单，可修复网络后重跑。钓鱼26张物品/装备图也已缓存（约5 MiB）；角色库516张现存图片已完整解码通过。

这些固定图片可离线读取，但QQ发送图片仍需要网络。用户头像、动态截图、实时生成图等不属于可预先完整下载的固定资源。未来上游清单增加图片时需重新补齐；P010暂缓功能未处理。


### 其余塔罗牌阵

私聊或群聊中发送 `塔罗牌阵时间之流`（3张）、`塔罗牌阵四要素`（4张）、`塔罗牌阵五牌阵`（5张）、`塔罗牌阵吉普赛十字`（5张）、`塔罗牌阵马蹄`（6张）、`塔罗牌阵六芒星`（7张）。前缀可替换为 `小阿卡纳` 或 `混合` 选择牌池；默认“塔罗”为大阿卡纳。展开合并消息可查看各牌位的牌图、正逆位和释义，最后为文字汇总。同一牌阵不重复抽取同名牌。未附加问题时不调用AI解读。

连续验收时，每项收到后间隔至少10秒；遇到限频提示，等待后再试。7种牌阵的3类牌池已完成隔离生成检查，QQ实际显示与发送者仍按实机结果分别记录。
