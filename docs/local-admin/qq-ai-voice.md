# QQ AI 语音命令

## 配置与使用

语音配置保留共享声音名称/ID及旧生成用群号，存于`data/airecord/recordconfig.db`，不在现有控制库备份范围内；维护时另做一致备份。主人可私聊使用`设置AI语音群号123456789`、`设置AI语音模型`（选择返回列表的序号）、`查看AI语音配置`。更换声音不改模型人物、DeepSeek配置或Agent记录。发送始终使用当前群，旧生成群号不再参与路由。

在有效响应的群中发送`@机器人 发送AI语音语音调试成功`。群主、管理员或机器人主人可使用，普通成员群内不具备该显式命令权限。需启用airecord插件，机器人在当前群内且QQ声聊能力可用。

本机NapCat v4.18.28的`get_ai_record`会直接向参数指定的群发送语音，再返回资源地址；它不是无副作用的生成接口。为避免群重复语音及私聊内容发到群，修复后群内仅调用一次`send_group_ai_record`，目标始终为当前群，不读取共享生成群号，也不再获取资源、转发语音或兜底重试。该版本成功回执的message_id固定为0，按status/retcode判断接口是否成功，不能以0误判失败。失败或回执不明给出提示，不重试。

QQ内置AI语音在当前适配器中不提供安全的私聊生成接口。私聊发送显式命令会给出仅支持群聊的提示，不调用任何语音接口、不发送群消息。共享生成群号暂保留以兼容原配置，不用于本修复后的发送。空文字、缺声音、无效群在调用前提示。

后台会话的“以AI语音输出”仍只作用于原普通AI聊天回复：群内采用相同的直接发送接口；私聊保留文字回复，不向生成群发送。Agent成功的文字动作和`/gpt`保持现有发送方式。本轮不新增语音输入识别，不自动把Agent回复改为语音。QQ语音和模型文字输出由不同服务处理。


## 选择声音与取消

主人私聊发送 `设置AI语音模型`，收到列表后，在两分钟内回复从0开始的序号。序号对应当次列表的角色ID；同一角色在多个分类重复出现时只列一次。输入不存在的序号会提示重新选择，输入 `取消` 退出且保持原配置。整个选择过程最多两分钟，错误输入不会重新计时。

等待期间，同一用户同一会话的回复优先交给选择流程，不再由普通AI聊天抢答；其他人的回复和群内回复不能替代私聊选择。需执行其他命令时先取消。成功或取消后不再迟发超时提示。声音配置全局共享且保存后立即生效；试听其他声音后可重新选择原声音恢复日常设置。

实机检查可先用 `查看AI语音配置` 记录原声音，然后进入选择并取消，检查原声音不变；再选择另一声音，在授权测试群发送 `发送AI语音声音验收测试`，确认能播放后恢复原声音。私聊显式语音命令只返回群聊使用提示，不会把私聊文字发送到群里。

选择或恢复声音只发送文字确认，不会自动私聊发送QQ目录的试听音频。需要试听时，请在授权群显式使用“发送AI语音”。选择列表里即使包含试听地址也不会自动播放。

旧生成群号配置只允许主人私聊修改，接受正整数（可带首尾空白），空值、非数字、非正数及超出int64范围的值不会写入。配置查询同样限主人私聊，成功修改重启后保留；它不改变当前群直接发送语音的路由。2026-10-23新增19项配置边界隔离检查通过，不需要更改真实群号进行验收。
