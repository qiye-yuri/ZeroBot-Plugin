R8 已于2026-10-24合并部署。刷新后台并用原密码登录后，可从会话配置核对点击“设置此会话搜索”；原配置和搜索启用范围保持。验证见[部署验收](self-test.md#r8-合并部署验收)。

Agent 会话的[配置核对](conversation-check.md)可查看本机器人会话已保存的全局/会话开关、允许角色和密钥配置状态。核对不执行搜索，也不把允许角色列表当作具体发言者的实际权限结论；修改搜索配置沿用本页步骤。

# N3 联网搜索

2026-10-17：R5/R6/N3已合并master并部署。日常实例已显式配置独立搜索密钥，开启全局搜索及原机器人与主人的私聊，仅允许主人角色；其他会话未开启。真实QQ入站、一次搜索取得5条结果、回复中5个实际来源及平台回读均已通过，见[真实QQ验收](self-test.md#deepseek-搜索启用与真实-qq-验收)。原模型、人物和其他会话配置保持。产品对新实例和未配置会话仍默认关闭。

首版只供 Agent 使用；每次请求 5 条，按实际可用结果返回并附来源，不抓取网页全文。来源来自搜索服务，不保证都属于官网；需要官方资料时应核对域名。

## 从当前会话快捷进入（R8）

登录后台，在“Agent 会话”读取机器人与群/私聊范围，点击“核对会话配置”，再点击“设置此会话搜索”。页面会自动进入 AI 设置，填入已加载的机器人、会话类型与完整编号，并读取搜索表单；未读取的范围输入不会改变目标。此操作只导航和读取，不保存、开启搜索或调用提供商。全局开关与密钥由实例共享，会话策略按机器人和群/私聊隔离。

已有搜索草稿时只确认一次：取消保留原页与草稿，确认后清除旧搜索表单并读取目标；其他 AI 表单草稿保留。记忆编辑等原有离开确认仍生效。读取失败时不保留旧目标的可保存表单；读取途中离开页面或退出登录会丢弃迟到结果，回来后可重新读取。修改后仍需显式点击“备份并保存搜索设置”，保存后供后续任务使用，无需重启。

## 配置与使用

1. 登录后台，进入 **AI 设置 → 联网搜索**，填写已连接机器人的 QQ、群号或私聊用户 QQ，点击“读取搜索设置”。搜索策略按机器人和群/私聊隔离。
2. 在同一表单配置 DeepSeek 官方 API Key，并打开“全局启用搜索”。密钥独立保存，不自动借用聊天或命名模型密钥；可以显式填入已有的官方 Key。填写的是DeepSeek平台Key，不是后台登录密码；搜索密钥框已标记为新凭据，提示浏览器不复用已保存的登录密码。当前值不回显，支持保留、替换、确认清除。清除前关闭全局开关。
3. 打开“允许本会话联网搜索”，选择允许角色。初始仅选择主人；群管理和普通成员需要明确勾选。这里沿用 Agent 已有角色划分，主人指机器人主人；群主与群管理员归入群管理。
4. 点击“备份并保存搜索设置”。保存本身不会联网；使用现有控制数据库备份和修订检查，无需重启。其他 AI 表单保存后如提示版本变化，请重新读取。
5. 在已开启 Agent 模式的对应会话提出问题，例如“搜索 Go 官方最近发布的版本，列出搜索结果并附来源”。机器人调用 `search_web`，取得标题、链接和摘要，再回复。没有启用 Agent、插件或消息响应时，单独打开搜索不会使消息触发。

全局开关和会话开关需要同时开启，且调用者角色在允许列表中。缺少配置时默认关闭；不会自动开放已有群、私聊或普通成员。GPT、群总结和普通聊天不自动联网，模型选择和 R5/R6 参数保持原流程。

## 结果、费用与限制

- 固定调用 [DeepSeek Search API](https://api-docs.deepseek.com/zh-cn/api/search/)，地址为 `https://api.deepseek.com/v1/tools/search`。仅提交模型生成的 `query`、`count: 5`、`need_content: false`，不自动附加原问题、QQ 身份、历史、记忆或配置。查询文本本身由模型生成，使用时不要要求搜索私密资料。
- 按[官方搜索指南](https://api-docs.deepseek.com/zh-cn/guides/search/)在 2026-10-17 的标价，搜索为人民币 5 元/千次成功且非空请求，约 0.005 元/次；以提供商实际账单为准。模型生成与继续回答仍按所选模型另计费。
- 每个任务最多尝试 2 次搜索，独立于历史/记忆的 3 次查询额度。每次最多 5 条，不足时返回实际数量；空结果和失败如实返回，均占本地尝试额度。不自动重试、不缓存、不切换服务商。
- 查询为 1～128 个字符；每次期限 10 秒，响应体最多 256 KiB，每条摘要最多 1,600 UTF-8 字节。只展示 HTTP(S) 来源，不访问链接、不调用 Fetch、不声称已读取网页全文。
- 搜索成功后，发送文字时会补齐模型省略的实际来源链接；一次任务最多累计 10 个来源。链接供核对，不能证明网页真实或结论正确；搜索资料不授予发送、记忆写入或其他动作权限。
- Agent 搜索后直接结束、尚未发送答复时，宿主直接回复本次实际结果与链接；没有资料时返回工具提示，避免转入普通聊天后遗漏搜索结果。
- 任务面板的“联网搜索”显示尝试、成功、空结果、失败和拒绝次数。成功包含空结果；这些是本地执行记录，不是精确账单。旧任务没有搜索摘要。

## 停止、禁用与恢复

搜索设置保存后沿用现有配置代次，旧任务停止继续执行；已经发出的搜索最多等待本次期限，返回后丢弃结果，不继续模型或发送。停止无法撤回已经提交给提供商的查询。

关闭全局开关可停止后续任务获得搜索工具；仅关闭会话开关则影响对应机器人会话。保存仍先备份；数据库恢复使用[维护说明](operations.md)中的现有预览/恢复流程。配置中保留的密钥随控制数据库备份保存，备份应留在本机受控目录。

保存失败先核对后台错误：版本冲突需要重读，凭据、余额或额度错误需要到 DeepSeek 平台核对。搜索 HTTP 错误只提供简短提示，不回传供应商响应正文或密钥，也不会把错误当作成功空列表。

## 开发复验

在仓库根执行 `go generate main.go`，然后运行：

```powershell
pwsh -File scripts/test-agent.ps1 -OutputName zerobot-search-validation.exe
```

统一入口使用离线 Chrome、模拟 HTTP/模型与合成 OneBot，不需要真实密钥。真实 Search 另行显式启用：在本机忽略的 `.local/search-credentials.json` 保存包含 `aiConfig.API` 与 `aiConfig.Key` 的 JSON 快照，API 必须为 DeepSeek 官方 HTTPS 地址；随后执行：

```powershell
go test scripts/test-real-model.go scripts/test-real-model_test.go scripts/test-web-search_test.go -count=1 -run '^TestWebSearchRealProviderRuntime$' -timeout=180s -v -args -validation-binary zerobot-search-validation.exe -real-search-config .local/search-credentials.json
```

此命令每次只发起一次真实 Search，可能计费；运行最终二进制，模型与 OneBot 仍为模拟，检查5条实际结果是否进入后续模型及平台回复。缺少显式参数时跳过真实验证，跳过不算通过。相对凭据路径从仓库根解析，不要把密钥放进命令参数或聊天；报告与原始证据在 `.local/n3/runtime/`，不得上传。


## 单独诊断已保存密钥（R9）

读取搜索设置后，可显式点击“测试已保存搜索密钥”，以固定公开查询测试全局已保存密钥，不必先开启业务搜索或运行 Agent。可能产生提供商费用；不会提交草稿、改动开关或消耗任务两次搜索额度。成功只说明本次基础请求通过，空结果与HTTP/网络/格式失败分别显示。用法见[搜索密钥诊断](search-probe.md)，R9 已合并部署；一次实际诊断通过，详见[验收记录](self-test.md#r9-合并部署与真实诊断验收)。
