# 凭据设置消息与 Agent 历史

主人设置聊天密钥（含 Agent、识图）、画图密钥或 B 站 Cookie 时，继续使用各插件原有命令和权限；本项不增加配置入口。B 站命令仍仅限主人私聊。

这些设置消息进入 Agent 历史时隐藏命令正文，保留消息编号、会话和工具调用信息；历史回放、滚动摘要和档案展示也识别旧记录中的同类命令。替换文本为“[密钥设置内容已隐藏]”。引用这些命令的正文也会隐藏；普通聊天和凭据设置的实际执行不受影响。

修复随新程序启动生效。旧原始档案不改写、不删除；此规则只识别明确的设置命令，不是任意密钥检测，不承诺识别已脱离命令正文的旧摘要或记忆，也不能撤销过去的模型请求。不得为验证而读取或发送真实凭据。

验证使用合成密钥、Cookie、独立数据库及假模型；已取消的 QQ 验收不再安排。实现、部署和上传状态见[交付记录](github-delivery.md)。
