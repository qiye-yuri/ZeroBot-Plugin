## 使用入口与兼容性

- [独立ASR](asr.md)：引用QQ语音后发送ASR；仅向独立识别接口提交转换后的音频。
- [独立TTS](tts.md)：发送TTS文字，合成后仅发送当前会话，不替代原QQ AI语音。
- [图片OCR](ocr.md)：OCR命令随附或引用一张图片，返回识别文字。
- [文件问答](document-qa.md)：先发送文件，再在15分钟内提问；按机器人、会话、用户和测试批次选取文件。
- [引用语音](quoted-voice.md)：群内回复语音并明确@机器人，转文字或按当前人物设定回答问题，沿用QQ连接端转写。

独立接口复用现有联网总开关、会话角色及搜索密钥，不自动开启。旧语音命令、普通聊天和已合入的链接阅读/深度搜索保持原入口；功能之间不自动回退重试。接入这些功能的安装需要常规备份升级和重启；本次上传不替换现有日常程序。
