# 消息撤回状态检查

撤回状态检查默认启用，无需后台开关，以当前机器人收到并保存的 OneBot 撤回通知为准，按会话和测试批次隔离，重启后仍生效。机器人离线期间没有收到的撤回通知，无法保证识别。

- 引用已撤回消息时提示“原消息已撤回”，不继续交给插件处理；平台缓存仍能读取原文也不能绕过检查。
- Agent 获取消息在读取前、返回结果后检查撤回状态。
- AI画图在下载参考图前、预算预留前、提交前及预览/最终结果发送前检查当前指令与引用消息。发现撤回后停止后续处理和发送。
- 已经提交的生成请求可能继续计费，保留预算占用；预留后、提交前发生撤回的极小时间窗口也会保守保留预留。已经发送的结果由现有“自动撤回”功能尝试撤回，不保证平台允许删除。
- 原始档案和撤回通知保留供本地审计；AI近期上下文、历史查询、后续滚动摘要排除撤回正文。受影响会话的旧滚动摘要移入审计保留区后失效。以撤回消息为直接来源的日常记忆不再自动召回。

检查无法收回已经发送给模型的内容，也不能保证删除由其他消息间接形成的旧记忆。平台通知到达与接口提交/发送之间存在并发窗口，无法提供跨平台原子取消。

部署后可在QQ正常使用：引用已撤回消息会直接收到提示；绘图处理中撤回指令，后续生成结果不再发送。使用与真实模型有关的验收时，遵守测试会话标记和空闲时段约束。
