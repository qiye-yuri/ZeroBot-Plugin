# 服务列表与使用方式

私聊发送 `/服务列表`，群内 @ 机器人后发送同一命令。英文别名为 `/service_list`。命令只读，不要求后台登录，不修改插件或群响应配置；保留原有定向和指令优先级规则。

回复改为合并聊天记录：首条说明总数量、页码、当前会话和翻页方式，其后每个插件独占一条，包含名称、功能说明、当前群/私聊启用状态，以及插件注册的使用说明。记录由机器人账号作为发送者，不冒充其他成员。

每页最多 20 个已加载插件，按现有插件优先级排序；无参数时是第 1 页，发送 `/服务列表 2` 查看第 2 页。页码不合法或超出范围会提示，不会发送空记录。关闭的插件仍展示，未编译插件不会出现。

单个节点最多 1200 个 Unicode 字符。用法过长时保留开头并明确提示发送 `/用法插件名` 查看完整说明，例如 `/用法aichat`；原用法指令及后台“查看用法”保留。未提供用法的插件明确标注，不能把简介当成可执行指令。

群响应门控与插件开关分别生效，“启用”不保证所有成员都有命令权限；仍需遵守每个插件的 @、角色、时段、密钥等条件。合并记录发送失败会明确提示，不自动刷屏重发；真实 QQ 的显示与风控以实际验收为准。
