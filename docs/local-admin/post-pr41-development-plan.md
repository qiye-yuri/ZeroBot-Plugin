# PR41后的详细开发计划：一键重置任务视图

核对日期：2026-10-27（Asia/Shanghai）。源码基线为master `991dcb1f12d5a36578c42e20d07ae19033aeb63e`。PR #41已完成开发、部署验收及合入，范围见[最终验收清单](task-outcome-acceptance.md)。本文件是下一批设计，功能尚未实现；本次交付仅包含规划及索引、进度、自测、交付记录。

## 1 问题、目标与边界

任务视图已支持风险筛选、请求结果筛选、排序和按需展开。用户排查完无匹配结果后，需要分别恢复三个选择才能返回原始任务列表；现有“恢复默认提示”只恢复费用阈值，按现行契约会保留任务选择，不能把该按钮改成同时重置任务视图。

下一批增加“重置任务视图”按钮：在当前已读取快照上，将风险恢复“全部任务”、结果恢复“全部结果”、排序恢复“原记录顺序”，并收起所有任务明细。用户仍停留在当前页面，可立即继续查看同一窗口。

不修改已应用费用阈值或输入框草稿，不清空请求统计、观察报告起点、会话数据或历史预算。外层“AI费用风险提示”“按任务查看用量”等折叠开合保持。完整报告、分组计算、结果含义和最多256条窗口契约沿用PR #41；不新增过滤条件、批量展开、搜索、持久化或后端接口。历史预算900000、[其他待验收与暂缓项](remaining-acceptance.md)保持。

## 2 交互契约

入口为登录后的“运行概览 → 模型接口请求 → AI费用风险提示 → 按任务查看用量”。在三项选择之后增加原生`type="button"`按钮，建议ID为`model-task-reset`，沿用次要按钮样式。说明文字明确：“恢复任务筛选与排序，并收起明细；不改变费用提示阈值或请求数据。”无需额外权限或确认框，点击不发送网络请求、不触发模型调用。

| 场景 | 点击后的结果 |
| --- | --- |
| 任意风险、结果与排序组合 | 三项恢复all/all/original，按原记录顺序显示完整任务集合 |
| 当前条件无匹配 | 返回当前窗口的全部组；不能将无匹配误写成请求为空 |
| 一个或多个任务展开 | 全部收起；不清空外层折叠区，按钮键盘焦点保持 |
| 三项已默认，但仍有展开任务 | 按钮可用，仍可收起明细 |
| 三项默认且全部收起 | 重复点击结果不变，无额外提示弹窗 |
| 有效空窗口 | 按钮可用，显示原空窗口文案，不生成任务或零用量结论 |
| 数据不可用或读取失败 | 与三个选择一起禁用，不重新显示旧请求；恢复后按现有刷新规则可用 |
| 阈值有未应用草稿 | 草稿和已应用值各自保留；重置任务列表仍使用已应用值计算风险说明 |
| 自定义阈值已应用 | 保持自定义阈值；与“恢复默认提示”职责分开 |

按钮的可用性仅跟随现有有效任务快照，不再建立“是否已修改”的状态标记。认证失效、离页、重登及跨启动继续沿用现有生命周期。重置后同页自动刷新保持默认选择，已经收起的任务不能自行重新展开；此后用户再次展开的同键任务仍按PR #40规则保留展开和摘要焦点。

无匹配状态下按Tab可到达按钮，Enter和空格都可操作。按钮使用现有布局；320px窄屏与1280px宽屏不得横向溢出，标签、说明不得被遮挡。只有出现可复现布局问题才增加局部样式，不顺带重做概览布局。

## 3 源码落点与最小实现

以下位置已按基线核对，不依赖外部新库或未存在的API。

| 文件/函数 | 已有职责 | 本批修改 |
| --- | --- | --- |
| [index.html](../../internal/localadmin/assets/index.html)任务区域 | 三个原生选择、组合规则说明与任务容器 | 增加一个初始禁用的按钮及简短说明 |
| [overview.js](../../internal/localadmin/assets/overview.js)的resetModelTaskView | 恢复三项选择并清空任务DOM；供离页和退出调用 | 保留现有清理语义，供新按钮复用 |
| 同文件renderModelTaskView | 生成匹配任务、维护控件禁用及展开/焦点 | 将新按钮纳入现有可用性更新 |
| 同文件现有click处理方式 | 原生按钮动作与认证检查 | 点击新按钮时按顺序调用resetModelTaskView、renderModelTaskView |
| 同文件clearModelRequests、showOverview、resetOverview | 快照失效、离页与退出清理 | 核对新控件跟随原流程，无需新增全局生命周期 |
| [test-model-cost-hints-ui.mjs](../../scripts/test-model-cost-hints-ui.mjs) | Chrome交互、下载及生命周期测试 | 增加针对用户操作结果的用例，复用现有夹具 |

不要将renderModelTaskView直接加入resetModelTaskView内部：该函数也在离页和退出时调用，在这些路径重新渲染可能短暂恢复应清理的旧内容。按钮事件组合“清理→重绘”即可；它没有异步工作，不需要锁、队列、重试或请求取消机制。

沿用既有认证与DOM边界处理，不为固定三个控件建立通用表单重置器、命令框架、兼容层或缓存。不要增加独立的展开状态副本；清空任务容器后重绘即可自然收起。若现有布局足够，不改CSS。分组、整数小计、selectModelTaskGroups、buildModelUsageReport及独立报告校验器无需改动。
