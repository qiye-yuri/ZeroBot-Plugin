# 猜词游戏

P046猜成语并入P097 `wordle`。群内使用，服务列表只有一个猜词入口。`/启用 wordle`、`/禁用 wordle` 按现有服务管理权限控制两种模式；旧 `handou` 独立开关不再生效。P097原开关状态沿用。

| 模式 | 新入口 | 保留的旧入口 |
| --- | --- | --- |
| 中文成语 | `个人猜词 中文`、`团队猜词 中文` | `个人猜成语`、`团队猜成语` |
| 英文单词（默认五字母） | `个人猜词 英文`、`团队猜词 英文` | `个人猜单词`、`团队猜单词` |
| 英文六/七字母 | `个人六阶猜词 英文`、`团队七阶猜词 英文`等 | `个人六阶猜单词`、`团队七阶猜单词`等 |

个人模式仅发起者答题，团队模式允许本群成员答题。同一群一次只能运行一局，中文和英文互斥，不同群可以分别开局。发送答案即可，不需要@机器人；符合当前答案格式的消息优先交给游戏处理，机器人自身消息不作答。

发起者发送 `结束猜词` 可结束当前游戏；团队模式的群管理员也可以结束。每次有效格式的作答会重置等待计时，105秒提醒，120秒未继续作答自动结束。仍沿用原用户触发限频，连续开局过快时应稍后重试。

中文模式有7次机会，展示汉字/拼音提示；`猜成语热门汉字`、`猜成语热门成语` 保留。英文五至七字母模式分别有长度加一次的机会，大小写均可。英文释义仍依赖外部翻译接口，失败时显示“释义暂不可用”，不因此取消游戏。

旧资源目录 `data/Handou/`、`data/Wordle/` 保留，成语习惯记录仍写原文件。已有本地词库优先读取，缺失时才下载；空词库及不合格式的记录会检查，避免空目标和索引错误。本次部署预备完整公开词库，填充缺失文件，不覆盖已有词库或习惯数据。

本批删除P045猜歌、P042原神抽卡、P023国际象棋、P068牛牛、P079打劫的源码、启动注册和用户列表入口；旧数据保留。P058钓鱼及其他未指定功能保持保留。

### 跨群同时游戏

每个群有独立的游戏占用状态；同一个人可在两个群分别开局。在A群发送 `结束猜词` 不会结束B群的游戏；同一群的中文/英文游戏共享占用状态，已有对局时新开局会提示正在进行。开局命令仍受共享的每用户限速约束，短时间内跨群大量开局也可能被限速，测试时相邻开局至少间隔约5秒，不结束他人的现有对局。
