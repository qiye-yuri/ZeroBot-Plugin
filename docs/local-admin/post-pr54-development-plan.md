# PR54之后的开发计划：任务用量汇总表展示

日期：2026-10-28（Asia/Shanghai）。设计基线为master的17193fbf57f24f4e6746937f2032f87f1dc94d17，已核对origin一致。PR #50～#54已集中验收并依次合入，详见[最终记录](pr50-54-batch-acceptance.md)。当前QQ配合队列0/5。本轮只设计、检查和上传文档，不修改程序、不部署、不增加计数。

## 1 问题、目标与边界

当前任务视图按输入、缓存命中、缓存未命中、输出生成八行匹配/全窗口小计。累计功能已通过真实单组验收；随着字段增多，用户比较同一字段的两个范围需要反复读标签。下一批将小计改为三列表格，保持字段顺序及已知次数，让同一行直接对照匹配任务与全窗口。

这是展示改进，不增加筛选条件或计算指标。沿用modelTaskTokenTotal、现有完整组筛选和BigInt求和，不重新扫描原始usage、不增加后端、网络请求、持久化、费用估算、缓存率或报告字段。不把布局改进拆成多个QQ配合项。历史预算900000与[其他待验收/暂缓项](remaining-acceptance.md)保持。

## 2 入口和展示契约

未来入口：登录后台 → 运行概览 → 模型接口请求 → AI费用风险提示 → 按任务查看用量。沿用后台登录权限，实施并部署后刷新页面生效，无新增保存动作。本轮使用指南只链接规划，不声称表格已上线。

保留统计起点、窗口限制、匹配组数及请求覆盖说明；随后显示原生table，表头为“用量字段”“匹配任务”“全窗口”，固定四行：输入、缓存命中、缓存未命中、输出。每个数据单元格上行显示“N Token”或“未知”，下行显示“已知k/n次”。表格后保留统一口径说明，再显示原任务明细。

使用caption“当前窗口任务用量小计”，列标题使用th scope=col，字段行标题使用th scope=row；表格不加入Tab顺序。数据全部用textContent或文本节点构建，不拼接HTML。不改变原任务明细summary、键盘展开和焦点行为。

各字段known独立统计；匹配范围分母是匹配整组请求数，全窗口分母是当前快照请求数。已知0显示0 Token，不能显示未知；known=0显示未知，不能显示0 Token。无匹配但窗口非空时仍显示表格，匹配列全部未知、已知0/0次，全窗口列保持真实小计，并显示当前条件无匹配。有效空窗口、无效窗口及读取失败沿用简短提示，不显示空表。

输入与缓存分项不一致时仍分别保留有效单值，不反推输入。输出全部已知不代表输入/缓存全部已知；表格不使用颜色或图标表达“成功”“正确账单”。统一说明沿用：“各字段仅合计已返回的有效Token值，已知次数分别计算；未知不补零，缓存分项不反推输入，不代表完整用量或费用。”

### 固定样例

关联任务A有两次请求，分别为(input,hit,miss,output)=(100,60,40,10)和(未知,0,未知,未知)；独立请求B为(30,10,20,5)。共2组3次。按“输出部分已知”筛选，仅A匹配。

| 用量字段 | 匹配任务 | 全窗口 |
| --- | --- | --- |
| 输入 | 100 Token；已知1/2次 | 130 Token；已知2/3次 |
| 缓存命中 | 60 Token；已知2/2次 | 70 Token；已知3/3次 |
| 缓存未命中 | 40 Token；已知1/2次 | 60 Token；已知2/3次 |
| 输出 | 10 Token；已知1/2次 | 15 Token；已知2/3次 |

上述分号在页面中为换行，不拼成长字符串模拟列。切换“独立请求+输出部分已知”后匹配0/2组、0/3次，匹配列全部未知0/0，全窗口四行保持。单个有效0样例显示0 Token、已知1/1；两个有效MAX_SAFE_INTEGER相加显示18014398509481982 Token、已知2/2，不转换成Number或科学计数法。

## 3 布局与生命周期

表格宽度占满当前内容区，三列允许换行；字段列保持可读宽度，两个范围列等宽。长整数只在必要处换行，不截断、不省略、不缩小到难以阅读的字号；数字与已知次数分层显示。320/640/768/1280px明暗主题均需验证，表格及页面不产生水平溢出。优先局部class样式，不改全局table或p规则，不引入布局依赖。

所有五类筛选仍按组取交集；风险和结果可由组内不同请求命中，汇总整组。排序与展开不能改变数值。阈值草稿不改变风险范围，应用和恢复默认阈值后重算；重置任务视图恢复全部范围、原顺序并收起明细，保留阈值与草稿。

手动/自动刷新用新快照替换表格，不追加或累加。可见同键任务的展开和summary焦点继续保持，表格重建不能抢焦点。跨启动、256窗口淘汰、读取失败、恢复、离页、退出与认证失效沿用现有清理路径，不留下旧值。

完整JSON导出仍为version=1及完整taskBreakdown，表格只用于页面。固定快照和阈值下，筛选/排序/重置前后完整报告除exportedAt外一致；实际刷新导致checkedAt变化须明确排除时间差，不掩盖请求或任务内容变化。
