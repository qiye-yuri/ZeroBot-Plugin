## AI画图帮助 · 尺寸 --size

```text
AI画图帮助 · 尺寸 --size

常用写法：
--size=1k：1024×1024方图
--size=2k：2048×2048方图
--size=2k-landscape：2048×1152横图
--size=2k-portrait：1152×2048竖图
--size=4k 或4k-landscape：3840×2160横图
--size=4k-portrait：2160×3840竖图
--size=1536x1024：标准横图
--size=1024x1536：标准竖图
--size=2880x2880：最大方图
--size=auto：由模型选尺寸，预算按允许的最大尺寸预留

例：AI画图 --size=4k-portrait 一张竖版旅行海报
自定义例：AI画图 --size=1920x1088 山间公路

GPT Image 2/2.5要求：两边为16的倍数，单边≤3840，长宽比≤3:1，总像素655360–8294400。4096x4096和1920x1080不合法。超过2560×1440总像素属于实验性范围，包含2K方图和4K。
旧模型1.5/Mini只支持标准三种尺寸及auto，不支持2K/4K。仅在描述里写“4K”“横图”不会修改API尺寸。QQ可能压缩显示，聊天缩略图不代表原始像素。
```

## AI画图帮助 · 质量 --quality

```text
AI画图帮助 · 质量 --quality

可选值：
low：低档
medium：中等
high：高档
xhigh：超高，仅GPT Image 2.5
max：最高，仅GPT Image 2.5
auto：模型自动选择，写--quality=auto，预算按最高档预留

例：AI画图 --size=2k --quality=max 一座细节丰富的城堡

不写--quality就沿用后台保存的档位，不固定为medium。提高质量通常增加用量与等待时间，并不保证每次效果都更好。
GPT Image 2和旧模型不支持xhigh/max。原硅基流动协议不发送此quality参数；要使用这些档位需OpenAI兼容接口。

实际默认参数请到后台读取；主人私聊“查看AI画图配置”可核对接口、模型和密钥设置状态。帮助不会显示实际接口或密钥。
```

## AI画图帮助 · 输出、张数与审核

```text
AI画图帮助 · 输出、张数与审核

--background=auto / opaque / transparent
自动 / 不透明 / 透明背景。透明背景必须配PNG或WebP。
--format=png / jpeg / webp
输出文件格式；JPEG值写jpeg，不写jpg。
--compression=80
值可填0–100的整数。只对JPEG/WebP发送；PNG忽略该值。
--n=2
值可填1–10的整数，表示一次生成张数，预算按张数预留。
--moderation=auto / low
标准自动审核 / 较宽松；low仍受服务商内容规则限制，不保证请求被接受。

透明PNG：
AI画图 --background=transparent --format=png 一枚叶子徽章
两张WebP：
AI画图 --n=2 --format=webp --compression=80 森林小屋，两种构图
JPEG：
AI画图 --background=opaque --format=jpeg --compression=90 海边风景
审核：
AI画图 --moderation=auto 水彩风格的花束

transparent不能配jpeg；无效组合会在请求前拒绝。QQ可能重新编码图片，不保证保留API原始格式或透明度。
```

## AI画图帮助 · 流式预览

```text
AI画图帮助 · 流式预览

--stream=true：启用流式
--stream=false：关闭流式
--partial-images=0 / 1 / 2 / 3：期望的预览图数，须配合--stream=true
0表示只等待最终图。实际预览数可能少于所填数量；预览会额外占用预算。

例：
AI画图 --stream=true --partial-images=2 --size=4k 云海中的城堡
只要最终图：
AI画图 --stream=true --partial-images=0 水彩森林
关闭流式并清除预览：
AI画图 --stream=false --partial-images=0 海边日落

如果后台保存了预览数2，仅写--stream=false会与继承的预览数冲突；关闭时同时写--partial-images=0。
预览消息会标注“非最终图片”。收到预览不代表成功，最终完成后另发结果。断流或超时仍会报失败，保留本次预算占用，避免远端已收费后重复放行。等待上限由主人在后台设置，普通画图参数不能修改。
```

## AI画图帮助 · 预算与限制

```text
AI画图帮助 · 预算与限制

预算按北京时间自然月计额，所有画图会话共用。每次先预留再请求；余额不足或已到上限会停止生成。重启、换模型不清零，下月新请求使用新额度。预算设0表示停止，不是无限制。

预留随尺寸、质量、张数、提示词和预览数变化；auto按最高档/最大允许尺寸预留。它是保守预算估算，不等于OpenAI实际账单。失败、超时、断流和发送失败不自动退款。
未知价格或账本错误不调用接口。兼容服务价格由主人核实，按每张最高总价×张数预留；确认免费的本地服务才能填0。

普通成员不能用画图参数修改预算。后台读取预算状态不会生成图片。
帮助只提供静态说明：查看帮助、尺寸速查和示例不调用模型、不占预算；发送一条真正的“AI画图 图片描述”才会尝试生成。

常见问题：
连接超时→主人检查画图专用代理与等待上限。
400→核对模型及参数组合。
401/403→核对密钥和模型权限。
429→检查服务商额度/限流。
无法发送→检查OneBot连接和QQ图片权限。
```

## AI画图帮助 · 参考图 / 带图绘制

```text
AI画图帮助 · 参考图 / 带图绘制

两种发送方式：直接附图和命令一起发；或回复当前会话中的图片消息，再发送AI画图 修改要求。
例如：
AI画图 保留这张图的主体，把背景改为海边
AI画图 --size=2k 按这张参考图的风格绘制一座小屋

有附图：走图片编辑/参考图接口，原始图片字节作为图片输入发送给绘图模型。
没有附图：按原来的文生图方式生成。
回复中会显示“已读取N张参考图”和最终参考图数量，便于核对。图片读取失败会停止，不会偷偷忽略图片继续画。

请同时发送图片和文字；先单独发图再单独发命令，不会自动续用上一张图。支持引用当前会话的图片（包括机器人发来的图）；读取不到、已撤回、跨会话或测试范围不匹配会停止并提示。当前消息附图和引用消息图片都作为参考图，先附图、后引用图。多图按消息里的顺序提供，最多16张；每张8MiB、合计32MiB以内，PNG/JPEG/WebP，单边≤8192、总像素≤16M。不支持本机任意文件路径、GIF、蒙版或涂画标记。

输出尺寸、质量、格式及张数仍按本条参数或后台默认，不自动等于参考图尺寸。
接口类型须为openai，地址仍填完整/images/generations，程序自动调用同一服务的/images/edits；兼容服务须支持JSON图片编辑请求。

参考图另有输入费用。官方接口默认每张参考图额外预留$0.25×输出张数，可在后台调整；这是预算额度，不是官方每张报价。原月预算不变，余额不足仍会停止。
```
