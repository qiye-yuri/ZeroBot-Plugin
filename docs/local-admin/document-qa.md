# 文件问答

本批整理既有实现及合成测试。原完整工作区的验证与本次独立发布范围分别记录，见[语音与文档接口交付](voice-document-delivery.md)。

## 使用

1. 在当前群或私聊发送一个文件。
2. 15分钟内发送`文件问答 你的问题`；群聊需真实@机器人。
3. 省略问题时默认总结文档。继续提问仍需以`文件问答`开头。

支持PDF、Word（DOC/DOCX）、PowerPoint（PPT/PPTX）。只使用当前机器人、当前会话、当前发送者最近发送的一个文件；其他群员的文件不能被本命令选中。同一用户发送新文件会替换旧记录；多文件消息清空选中记录，防止误用旧文件。重启后需重新发送文件。

只缓存文件标识、文件名、大小等元信息15分钟，不会在收到文件时自动下载、上传或回答。元信息上限128条，超出时移除最早记录；测试批次单独隔离。原始文件和解析文字仅在请求内存中使用，不新增持久化文件副本。

## 权限、解析与模型

复用AI设置中的联网搜索总开关、会话范围和角色权限；原有主AI插件及聊天响应设置仍须允许处理。解析使用已保存的DeepSeek搜索密钥和独立OCR接口，purpose为text_recognition；回答使用当前Chat或Agent模型入口。模型未准备好时不先上传解析。

本版是文字问答：扫描文字可交给OCR解析；图表、照片等视觉内容不提供给回答模型，不宣称理解其含义。文档内容作为不可信资料传入，不作为OneBot操作或工具指令执行；回答要求注明解析页码。模型引用页码仍可能不准确，需结合原文复核。

单文件最大20MiB。文件类型同时校验扩展名及PDF/旧Office/OOXML结构；最终有效性、密码保护等由解析服务核验。本地结构检查不代表文件可成功解析。

解析后超过100页、文字超过120KB、任一页被截断或没有文字时停止，不调用回答模型。页数和文字上限在解析完成后检查，因此此前的解析仍可能收费。

## 数据、费用与错误

每次问题最多一次解析请求和一次回答请求，不自动重试。重复提问会重新解析，产生新的解析费和回答token费用；本版不保留解析结果用于跨轮复用，也不自动携带之前问题。

解析仅发送文档字节和通用文件名，回答仅发送本次问题与带页码的解析文字，不发送QQ编号、人物设定或历史档案。QQ附件下载不附带模型密钥，不读任意本机路径，拒绝下载重定向和非允许文件来源。

下载最多30秒，整条流程最多约240秒，回答阶段最多60秒。超时不保证服务商已经停止解析或计费，因此不自动重试。后台现有模型统计记录回答请求/token，不包含OCR解析页数费用，不能据此推算完整费用。
