# 聊天链接阅读

当前状态：实现与相关合成回归已完成；本批发布范围见[接口整合交付](interface-refactor-delivery.md)。QQ收发未新增验收。

## 用法

私聊发送：

`读链接 https://example.com/article 请总结主要观点`

群聊先@机器人，再发送相同命令。省略问题时默认用中文总结。每次只接受一个HTTP/HTTPS公开网站域名链接；不自动读取普通聊天中出现的链接。需要追问时再次附带同一个链接和新的问题；本版为单轮阅读，不保留服务端网页签名供跨轮追问。

## 配置与权限

复用AI设置中的联网搜索总开关、机器人/群或私聊范围及允许角色。仅这些范围和角色允许调用；原有聊天响应开关仍生效。此功能不自动开启任何配置。

普通聊天使用当前Chat模型，Agent会话使用Agent模型。对应入口必须为DeepSeek官方HTTPS接口（根地址、/v1、/chat/completions或/v1/chat/completions）、OpenAI接口类型、deepseek-flash和已保存模型密钥。联网权限的既有搜索密钥仍用于满足原搜索设置条件，链接阅读请求实际使用所选模型入口的密钥。

仅发送当前链接、问题和该会话人物设定；不发送QQ编号或历史档案。声明deepseek_read_url，关闭思考，开启high内容安全；不开放搜索或本地Agent动作。每条命令发起一次模型请求，不自动重试。输出上限2048 tokens是每步上限，并非整轮费用上限；token与网页抓取分别按提供商规则计费。

请求最多等待90秒，若调用方已有更短的超时则沿用更短限制；响应最大2MiB，不跟随HTTP重定向。链接阅读与深度搜索共用请求处理，但仍分别使用各自工具和结果核验规则，无需新增配置。

## 结果和失败

只有服务端确认指定URL读取成功并返回网页签名，才展示回答及原始来源链接；不会把模型未读取网页的回答当作摘要。网页不可访问、需要登录/验证、审核拒绝、服务错误、无有效结果会明确提示。截断回答标注内容不完整。原文正文不由内置阅读工具返回，不能用于更新监控的逐字证据核验。

现有模型请求统计记录请求及token；当前汇总不单独统计服务端抓取次数，不能用该统计估算完整账单。模型响应和页面内容均只作为文本，不作为OneBot动作执行。


## 验证范围

使用模拟HTTP响应验证权限、模型选择、请求参数、结果解析与失败不重试；不以自动化替代真实QQ验收。
