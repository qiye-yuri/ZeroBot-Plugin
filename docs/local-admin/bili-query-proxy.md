# B站查询使用进程代理

本批修复查弹幕、用户资料读取及“更新vup”共用客户端忽略环境代理的问题。HTTP目标读取HTTP_PROXY，HTTPS目标读取HTTPS_PROXY；NO_PROXY和Go标准的本地地址直连规则继续生效，对应小写变量也按Go标准处理。

沿用ZeroBot进程已有的启动环境，不新增配置字段、QQ命令或后台页面，不自动读取Windows图形化系统代理，也不把画图专用代理套用到B站查询。未配置环境代理时保持直连。修改启动环境后需重启ZeroBot，其他业务配置和OneBot不必更改。

本次不写入或修改用户的代理环境，只修复查询客户端对既有设置的使用。运行中的进程不会因另一个终端修改环境而自动更新；应在实际启动ZeroBot的宿主环境配置后重启。

原12秒HTTP请求超时、调用方总截止时间、TLS证书验证、响应大小及原有有限空JSON重试规则保持。代理失败仍明确报请求失败，不增加自动直连兜底或新重试策略。

修复证明查询会按进程配置选择网络路径，不保证第三方接口恢复、不等于历史所有超时都由代理引起；已取消的QQ验收不重新安排。开发和验证范围见[本批记录](bili-query-proxy-acceptance.md)。
