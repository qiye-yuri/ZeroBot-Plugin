2. 总结单独携带视频链接；成功、空内容和失败分别保留真实状态，不重复基础消息。失败无自动重试或模型兜底。
3. 总结HTTP设置12秒、2MiB上限和不跟随重定向；WBI签名继续复用依赖，不新增签名缓存/通用客户端框架。签名键获取不包含在这12秒内，但在基础消息之后进行。
4. 先用阻塞的假总结证明发送顺序，再覆盖开关关闭、基础发送失败、空总结、上游错误、超时/超大响应和重定向。
