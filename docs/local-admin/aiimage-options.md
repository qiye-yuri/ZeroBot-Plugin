# 画图可选项：2K、4K、格式、多张与流式预览

本页对应 **OpenAI Images API文生图（/v1/images/generations）** 的当前可选项。后台入口：AI设置 → AI画图 · 独立配置 → 读取画图配置。保存对后续请求生效，命令参数只覆盖当前一次，不修改后台默认值。

此次升级保留现有模型、质量、默认尺寸、预算、接口和密钥。新安装的质量默认medium；当前日常实例已按主人要求保存为Sunburst、high、1024×1024、每月100美元，本次不会改回medium。

## 参数清单

| 后台选项 | 可选值/范围 | 本次命令覆盖 |
| --- | --- | --- |
| 默认分辨率 | 标准尺寸、2K、4K、合法自定义尺寸、auto | --size=宽x高 / 2k / 4k / auto |
| 画图质量 | low / medium / high / xhigh / max / auto | --quality=max |
| 背景 | auto / opaque / transparent | --background=transparent |
| 输出格式 | png / jpeg / webp | --format=webp |
| 压缩质量 | 0–100，仅JPEG/WebP发送 | --compression=80 |
| 参考图额外预算预留 | 每张0.01–100美元，默认0.25；非API固定报价 | 仅后台 |
| 生成张数 | 1–10，默认1 | --n=2 |
| 内容审核 | auto / low；low仍有服务商内容限制 | --moderation=auto |
| 流式生成 | 关闭/开启，默认关闭 | --stream=true |
| 流式预览图 | 0–3，必须启用流式 | --partial-images=2 |
| 安全标识 | 可选匿名标识，最多128字节 | 仅后台，勿填密钥或个人信息 |
| 画图专用代理 | HTTP/HTTPS/SOCKS5/SOCKS5H地址，不含账户密码 | 仅后台，防止普通消息更改请求目的地 |
| 等待上限 | 30–1200秒，默认300秒 | 仅后台 |

接口地址、模型与密钥继续由主人私聊或后台设置；不允许普通画图命令覆盖。选项采用 `--名称=值` 格式，每个选项一次。提示词至少有一段正文，最多32000 UTF-8字节；参数错误会在预留预算及调用API前报告。

请求字段 `safety_identifier` 对应后台安全标识；`n`、`quality`、`size`、`background`、`output_format`、`output_compression`、`moderation`、`stream`、`partial_images`均已按适用条件发送。PNG不发送压缩参数，关闭流式不发送partial_images。安全标识留空时不发送。

`response_format`、`style`、`user`等已弃用字段不新增；GPT Image返回Base64，风格写在提示词中。OpenAI文生图API未提供seed、negative_prompt、采样器或步数参数，不伪造这些控件。图片编辑属于另一接口，同条QQ消息附图现可走图片编辑接口；蒙版和历史多轮编辑仍未接入，见[参考图用法](aiimage-reference.md)。[官方请求参数](https://developers.openai.com/api/reference/resources/images/methods/generate)。

## 2K、4K与合法尺寸

| 预设 | 实际请求尺寸 |
| --- | --- |
| 1K方图 | 1024×1024 |
| 标准横图/竖图 | 1536×1024 / 1024×1536 |
| 2K方图 | 2048×2048 |
| 2K横图/竖图 | 2048×1152 / 1152×2048 |
| 2560横图 | 2560×1440 |
| 4K横图/竖图 | 3840×2160 / 2160×3840 |
| 最大方图 | 2880×2880 |

GPT Image 2与2.5支持符合这些条件的自定义尺寸：两边都是16的倍数，单边不超过3840，长宽比不超过3:1，总像素655360–8294400。**4096×4096不合法**，1920×1080也因1080不是16的倍数而不合法，可用1920×1088。超过2560×1440的总像素为官方实验性范围，2K方图和4K也在其中。[官方尺寸约束](https://developers.openai.com/api/docs/guides/image-prompting#model-parameters)。

`--size=2k`表示2048×2048，`--size=4k`表示3840×2160；还有2k-landscape、2k-portrait、4k-landscape、4k-portrait别名。自然语言“画一张4K图”不会自动替换API参数，明确写--size或设置后台。

旧模型1.5/Mini仍只支持标准三种尺寸或auto，不能选择2K/4K；GPT Image 2不支持xhigh/max。Sunburst与Flare支持全部六档质量。禁止的组合在调用前拒绝。

## 示例

```text
AI画图 --size=4k 一座雨夜霓虹城市，横向构图
AI画图 --size=2k --quality=max 水彩风格的森林小屋
AI画图 --size=2160x3840 --quality=high 竖版旅行海报
AI画图 --size=1920x1088 --n=2 两种不同构图的海边风景
AI画图 --background=transparent --format=webp --compression=80 一枚叶子徽章
AI画图 --stream=true --partial-images=2 --size=4k 云海中的城堡
```

透明背景只可选PNG或WebP，JPEG组合会被拒绝。流式预览会作为标记“非最终图片”的QQ图片发送，最终完成后另发最终结果；有预览不代表已成功，流断开或服务错误仍算失败。最多等待后台所设时限，不自动重试。

API生成像素与QQ显示是两回事：平台可能压缩或重新编码图片，不能把聊天缩略图当作原始分辨率/透明度验收。原始API响应最大256MiB；超过上限会报告失败，保留本次预算预留。

## 预算随选项计算

- 仍按北京时间自然月计额，当前100美元配置保持。先持久预留再请求，余额不足、未知价格、账本错误不调用API。
- GPT Image 2/2.5用各自官方公式支持所有合法尺寸。2.5的low/medium/high/xhigh/max系数16/24/48/64/96；GPT Image 2使用16/48/96，不混用。
- auto质量按该模型最高档预留；新模型auto尺寸按2880×2880最大方图估价，此形状达到最大像素且具有最大网格。旧模型auto尺寸按最贵标准画幅、auto质量按high预留。实际输出由服务决定。
- 流式每个预览额外预留100图片输出token，按请求的预览上限计算；输出费用再加20%余量。多张请求对输出、预览及输入预留按张数乘算，宁可多预留，不因少返回预览自动退款。
- 兼容/本地服务的手动价格现表示**每张最高总价**，应覆盖输入、输出、预览及服务费，按n倍预留。默认n=1，旧配置金额不变。服务商的张数或选项支持仍须由服务商确认；明确免费才填0。
- 超时、断流、服务错误、发送失败仍保留预留；重启、换模型或恢复配置不清账。这是保守准入额度，不等同实际OpenAI账单硬上限。

## 画图专用代理

此前日常实例访问OpenAI直连超时，本机 `http://127.0.0.1:7897` 的不带密钥只读检查能到达接口。后台可以单独填写该代理，不改变接口地址、密钥或聊天/Agent代理设置。留空只沿用服务进程的代理环境变量，不自动读取Windows系统代理。代理必须运行；不可在普通画图消息里指定代理。

自动化使用本机模拟API、模拟代理和独立OneBot，覆盖参数载荷、4K/max估价、多张、流式部分/最终图、无效组合、旧表迁移及预算/重启门控。真实4K与QQ收件仍需按仓库空闲时段和测试隔离规则验收。
