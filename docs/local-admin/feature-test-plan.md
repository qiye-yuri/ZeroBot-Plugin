# 现有功能测试与去留方案

日期：2026-10-18。对象：当前主目录 ZeroBot-Plugin；源码基线 ec592fa476b8694b1da1982fbbe0f9b41b3337f8。R8～R10 等未实现规划不作为现有功能。测试结果见[本轮结果与去留清单](feature-test-results.md)，全部源码加载插件见[插件逐项清单](feature-plugin-inventory.md)。

## 判定规则

- 保留：有明确用途且对应测试通过；自动化、真实接口、真实 QQ 和硬件测试分别判定。
- 修复后保留：能稳定复现，已定位原因且有可验证的修复；修复后复测原失败及相邻功能，同步使用文档。
- 建议删除：用户明确不需要，或已证明关键依赖失效且没有可行替代。缺密钥、设备休眠、暂时断网、权限不足、没有测试账号或测试未覆盖不算“无法修复”。
- 待实机验收：证据不足，保留并标出缺项，不以历史通过或模拟结果代替本轮实机通过。
- 用户最初未指定不必要功能，后续已明确删除P022、P099、P100，其余项目仍按测试及用途评估。低使用频率、娱乐属性和功能相似仅用于排序，不自动构成删除理由。

删除顺序：明确条目和理由 → 检查引用、共享依赖、配置及数据归属 → 备份 → 移除加载、入口及专属实现 → 更新文档与测试 → 构建和相邻功能回归。共享库及用户数据不能随插件一并误删。暂未决定的功能可以先保持原状态，不能把“未启用”写成“已删除”。

## 执行顺序与证据

1. 固定源码、测试程序 SHA256、日常进程身份；确认原配置和工作区变化。原始日志、截图、模型密钥、QQ身份和档案只保存在忽略目录。
2. 跑统一回归：`pwsh -File scripts/test-agent.ps1 -OutputName zerobot-feature-audit.exe`。包含 SDK、存储、后台、浏览器、构建和隔离整机；这是模拟模型和 OneBot 测试。
3. 补跑 `scripts/test-*-ui.mjs` 全部现有页面测试。插件逐项补查权限、资源、配置和真实依赖；整机能启动不等于每个插件可用。
4. 真机预检：`scripts/test-onebot.ps1`、后台在线状态、实际设备只读探测；接口连接通过不能替代真实消息链路。
5. 真实提供商：先 `go run scripts/test-real-model.go` 预检，再以本轮构建执行 `-run -binary-name zerobot-feature-audit.exe -cases gpt,chat,agent,memory-save,history,memory,vision,summary`。使用合成资料及隔离 OneBot，消耗模型额度；仍不证明真实 QQ 收发。
6. 按下表进行真人 QQ、实际后台操作及设备测试。需要主人本人发起真实入站，不能注入事件冒充。群用例使用用户指定测试群及实际角色，禁言、踢人、退群等破坏性操作不作为常规验收动作。
7. 汇总逐项状态、失败原因、修复记录、复测结果及去留。完整测试未完成时发布阶段清单，不能宣称全功能验收完成。

每条记录至少包含：用例编号、版本/进程、前置条件、输入、预期、实际结果、证据位置、是否恢复原状态、去留意见。真实消息以入站→任务/请求→平台回执→客户端可见逐项关联；每次使用不同验收标记。

## 真人实机最小操作序列

前提：确认测试主人私聊、测试群、角色与当前开关；每条等回复后再发，GPT/群总结间隔至少30秒。模式切换和人物修改先留原值，结束恢复。

1. 主人私聊发送 `/gpt 只回复：验收-A01`，核对客户端及平台回读。
2. 使用QQ引用刚才消息，再发 `/gpt 写出引用消息里的验收代号`。
3. 当前Agent开启时发“请向当前会话回复验收-A02，然后结束”，核对发送动作和完成状态。
4. 发送纯色图片及“说明图片主要颜色”，核对识图调用。
5. 分两次要求保存并检索合成记忆、检索刚才测试历史；核对实际工具及准确编号/修订。
6. 发起一次联网搜索，检查每个展示来源对应实际搜索结果。
7. 在指定测试群验证总结、语音及角色拒绝；普通聊天另切换模式完成两轮并恢复。
8. 核对后台档案、任务、日志、统计增量和配置恢复情况。电量真实提醒单独等待自然阈值，不伪造真实电量证据。

没有指定测试群/角色或真人入站时，相应项目保持“待实机验收”。暂时无法执行不构成删除理由。
