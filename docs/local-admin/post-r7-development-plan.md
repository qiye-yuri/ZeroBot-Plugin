## 3. R8：从 R7 进入当前会话搜索设置

### 使用契约

登录后台、加载会话并核对配置后，在 R7 结果中点击拟新增“设置此会话搜索”。AI 页面显示相同机器人、群/私聊和编号，自动读取已保存搜索设置并定位表单。编号全程保持字符串；目标来自已加载的 `agentScope` 副本，不取尚未读取的输入草稿，也不在跳转后重新访问已被清除的 Agent 页面状态。

仅导航和读取，不保存、开启搜索、选择角色或调用提供商。全局开关/密钥共享，策略按机器人及会话隔离，保持原说明；进入已关闭的会话不能改变其关闭状态。

已有搜索表单草稿时只提示一次：取消保留当前页和草稿，确认后清除旧搜索表单再读取目标。其他 AI 表单草稿保留；原记忆编辑等页面退出约束仍由现有导航处理。读取失败不保留可保存到旧目标的搜索表单。退出登录、离开及迟到响应使用已有页面代次规则。

### 验收标准

1. 已加载私聊与同号群、两个机器人及大整数编号都进入准确标题和表单。仅修改未读取的输入不会改变跳转目标。
2. 搜索草稿取消后零读取、零保存；确认后只读取目标范围，其他表单草稿保持。失败、退出和迟到响应不显示旧可保存目标。
3. 从关闭的会话进入后仍关闭。导航仅发读取请求，控制配置、备份数量及提供商请求数不变。
4. 320px、深浅主题和键盘操作可用。原人物/参数快捷入口继续通过已有回归。

开始实现时同步[搜索用法](web-search.md)、[会话核对](conversation-check.md)、[档案说明](agent-archive.md)及[使用指南](user-guide.md)，写清跳转不保存、范围与草稿处理；不提前在使用步骤中宣称新按钮可用。

## 4. R9：显式诊断已保存的搜索密钥

### 使用范围与费用行为

在 AI 搜索设置区域提供拟新增“测试已保存搜索密钥”，按钮附近明确“会发送一次固定公开查询，可能消耗提供商额度”。读取、保存、导航以及 R7 核对都不触发诊断。

固定查询建议为“Go 编程语言 官方文档”，实现时固定在服务端；只发送现有 Search 请求的 query、count=5、need_content=false。不使用实际会话问题、QQ身份、历史、记忆或草稿，不抓取结果网页。首版只显示结果数量和诊断状态，不回传标题、摘要、链接或提供商原始响应。

密钥为全局已保存值，因此诊断请求不需要机器人/会话参数，也不测试发言者权限。首版按钮放在已读取的搜索表单内，使用该表单的修订和密钥配置标志；读取仍按原步骤选中已连接机器人与会话，仅用于取得保存设置，不新增全局搜索读取端点。全局或会话搜索关闭时可单独测试已保存密钥，按钮和结果明确“不代表已启用会话搜索”。没有已保存密钥时阻止调用；表单中新填但未保存的密钥不参与诊断。不会为了测试而临时开启业务搜索或伪造一个主人 Agent 任务。

### 请求与复用设计

拟新增受现有登录、来源及 CSRF 保护的 `POST /api/ai-search-test`，输入仅为已读取的配置修订 `revision`。服务端读配置、核对修订并固定快照；版本变化返回现有冲突语义，缺密钥和非法修订在请求提供商之前失败。请求不接受任意 URL、Key、提示词或会话目标。

当前 `third_party/zbputils/chat/web_search.go` 的 `(*WebSearch).search` 同时实现 HTTP 请求和结果解析，尚没有可从后台直接调用的无任务接口。实施时将这个实际出现第二个调用点的请求/解析部分提取为小型函数，参数为上下文、现有 HTTP 客户端、密钥和查询，返回原 `WebSearchPage` 及最少的安全诊断元数据。具体名字在实施时按现有包结构确定。

Agent 的权限、每任务两次额度、计数、来源补齐、停止/代次检查与回复仍由原 `WebSearch.Execute` 管理，公共请求函数不包含这些副作用。保留原业务页面结构及错误文字；为了显示 HTTP 状态只增加有实际用途的非持久化类型，不把原始错误正文或凭据传回后台，也不改业务任务表。

沿用固定地址、10秒请求期限、禁止重定向、256 KiB响应及现有合法来源解析。后台响应写入期限须留出请求结束后的写入时间，可沿用 R3 的单接口 deadline 做法，例如15秒；不全局放宽后台期限。诊断传入请求上下文，业务调用保持原有停止/返回语义，不能在抽取时顺带改变 Agent 生命周期。

复用 `Server.probeActive` 的单个诊断在途门控，模型诊断和搜索诊断互斥，直接提示等待，不建队列、不重试。前端复用现有诊断 busy/epoch 逻辑所需的小函数，与模型按钮统一显示在途状态，避免两个页面模块各自添加一套调度状态。

### 结果与状态契约

| 结果 | 判定 | 页面含义 |
| --- | --- | --- |
| success | 返回格式和合法来源通过现有解析，数量1～5 | 仅本次搜索基础调用可用 |
| empty | 合法协议的结果数组为空 | 本次调用完成、无匹配；不能写成认证失败或“已经找到资料” |
| http_error | 提供商非成功HTTP状态 | 显示状态码和简短提示；401等状态保留以便排查，不透出原正文 |
| network_error | 连接、读取或超时失败 | 本次未取得可验证资料；一次调用结束 |
| invalid_response / response_limit | 非法协议、没有合法来源或超过原容量 | 如实报解析/容量问题，不能当作空结果成功 |

结果字段限于修订、测试时间、耗时、分类、HTTP状态（实际获得时）、合法结果数及固定简短提示。诊断不占 Agent 搜索尝试或本地历史/记忆额度，不进入业务模型统计，不保存为任务、聊天或长期报表。

结果仅保留当前页面。重新读取后发现修订不同，标为历史结果；另一个页面的配置变化不会在无轮询时自动被发现，因此只描述“基于当前已读取的保存版本”。退出清除结果，在途请求按原期限/上下文结束，不声称已撤销提供商费用。保存仍沿用原备份和修订流程，不自动再测试。
