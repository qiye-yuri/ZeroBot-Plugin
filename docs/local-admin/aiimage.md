# AI画图：接口、质量、分辨率与月预算

画图使用独立配置，不借用聊天、识图或Agent的接口、模型及密钥。后台与主人私聊设置共用 `data/aiimage/aiimage.db`；保存后下一次画图生效，无需重启。插件开关、响应与封禁规则仍适用。

## 后台设置

登录后台 → **AI 设置 → AI画图 · 独立配置 → 读取画图配置**。

| 字段 | OpenAI示例 |
| --- | --- |
| 接口类型 | OpenAI / 本地兼容接口 |
| 图片生成接口地址 | https://api.openai.com/v1/images/generations |
| 画图模型名 | gpt-image-2.5-flare（或gpt-image-2.5-sunburst） |
| 画图质量 | 中等（默认，发送quality=medium） |
| 默认分辨率 | 1024×1024（默认） |
| 每月画图预算 | 100美元（默认）；0表示停止，不能用0取消限制 |
| 兼容/本地服务每张最高总价 | 官方接口留空，自动按已核实价格估算 |
| 画图密钥操作 | 首次选“替换为新密钥”，只填API Key，不加Bearer前缀 |

点击“备份并保存画图配置”。已有密钥可选“保留当前密钥”；清除需勾选确认。原密钥不回显，保存成功会清空新密钥输入框。读取/保存不会调用模型或产生图片费用。修改被其他页面或私聊抢先保存时拒绝覆盖，需重新读取核对；未保存草稿有提示，放弃只影响该表单。

现已支持全部适用文生图参数：2K/4K、自定义尺寸、low/medium/high/xhigh/max/auto、背景、格式、压缩率、1–10张及流式预览。新增画图专用代理和等待上限。当前日常配置仍为Sunburst/high/1024×1024/100美元；完整选项和限制见[画图可选项](aiimage-options.md)。

## 画图与分辨率

```text
AI画图 一只穿宇航服的橘猫，水彩插画风格
AI画图 --size=1536x1024 日落海边，横向构图
AI画图 --size=1024x1536 一位旅行者，竖向海报
```

当前支持标准三种尺寸、2K/4K预设及合法自定义尺寸。`--size=宽x高`覆盖后台默认尺寸，计价也按该尺寸；每条只允许一个尺寸参数。没有参数就使用后台默认。提示词中的“横图”“4K”“1920×1080”仅作为文字描述，不会自动修改API尺寸；不支持的--size在调用前拒绝，不能将“4K风格”当作实际4K像素。尺寸是向服务请求的像素规格，不是对兼容服务返回文件的强制重采样。

GPT Image 2/2.5现按官方公式计价，开放全部合法尺寸；旧模型保持其标准尺寸限制。同条QQ图文消息支持参考图生成/编辑；历史多轮改图和聊天Agent自动调用未接入。详见[参考图用法](aiimage-reference.md)。

## 月预算与自动停止

- 默认每月100美元，按Asia/Shanghai自然月计额，全实例所有画图会话共用。
- 先写入预算占用再发请求；不足本次预留或已经达到上限，直接停止，不调用模型。并发预留使用数据库条件写入，重启仍保留；更换密钥或模型不重置已占用额度。
- 每月1日北京时间00:00后新请求使用新月份额度；旧月份在途请求留在原月份。历史记录保留，无需定时任务。
- 官方接口：按相应模型/质量/尺寸的公开图片输出价格或官方计算器估价，加20%输出余量，再加提示词UTF-8字节数及1024额外token的输入预留。这是保守预算估算，不是服务商账单或充值余额。不会因为实际输入较少自动退款。
- 超时、HTTP失败、坏JSON、无图片及进程中断无法证明远端未收费，预留不自动释放；后台显示“未确认/处理中”。图片已生成但QQ发送失败也保留占用，重试会再次占用。
- 预算降低到当前占用以下立即阻止后续生成；提高预算可继续放行。当前版本没有清零或批量退款按钮。
- 未知模型价格、账本读取或写入异常会阻止调用，不按0美元放行。统计只涵盖本版本启用后的本bot画图，不包含此前调用、其他应用共用密钥的费用、税费或价格变动。

**实际账单可能与估算不同；本地预算控制不等于OpenAI账户硬性扣费上限。**兼容服务自定义价格必须由管理员核实，填低会低估真实费用。官方价格表核对日期为2026-10-29，服务商调价后须更新计价规则。

预算账本单独位于 `data/aiimage/aiimage.db.budget.sqlite`，不随后台配置快照恢复。不得删除或用旧快照覆盖账本来回退程序，否则会丢失已登记占用。升级没有导入旧版费用；旧程序无此门控，回退到旧程序不能声称预算仍受保护。

## 模型价格对比

下表为1024×1024**图片输出**价格，另加提示词输入；不是本bot含余量后的预算扣减。来源：[OpenAI官方图片计费说明](https://developers.openai.com/api/docs/guides/image-generation#calculating-costs)。

| 模型 | 低质量/张 | 中等质量/张 | 高质量/张 | 当前预算接入 |
| --- | --- | --- | --- | --- |
| gpt-image-1-mini | $0.005 | $0.011 | $0.036 | 已支持；官方标为Deprecated |
| gpt-image-1.5 | $0.009 | $0.034 | $0.133 | 已支持；官方标为Deprecated |
| gpt-image-2 | $0.006 | $0.053 | $0.211 | 已支持；适合当前有明确预算的配置 |
| gpt-image-2.5-flare | $0.00588 | $0.01317 | $0.05268 | 已支持，官方2.5专用计算器估价 |
| gpt-image-2.5-sunburst | $0.00588 | $0.01317 | $0.05268 | 已支持，同一官方估算组 |

2.5系列的标准计费：文本输入$5/百万token、图片输入$8/百万token、图片输出$30/百万token。文生图不含参考图输入；两模型的token用量可能不同，不能因token单价相同就断言每张同价，更不能套用GPT Image 2的单张成本。本次已核实官方页面实际引用的2.5计算器，按其独立系数接入；九组估价及计算方法见[GPT Image 2.5计费核实](aiimage-25-pricing.md)。[Flare模型说明](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)。1.5和Mini的Deprecated状态不是已停服结论，仍以账号可用性为准。

100美元预算、GPT Image 2中等正方形：仅输出价格理论约1886张；本bot加入20%输出余量及提示词输入预留后，短提示词约1400张，具体数量随提示长度变化，不作保证。

## 后续本地或兼容服务

保持独立接口接入能力：选OpenAI兼容模式，填写本地完整生成端点（例如 `http://127.0.0.1:8000/v1/images/generations`）和实际模型名；无鉴权服务清除密钥。填写“兼容/本地服务每张最高总价”，必须涵盖每张图片的输入、输出、预览与服务费，多张按n倍预留；确认免费才填0，留空表示未知并阻止调用。免费请求不消耗美元额度，但月预算设为0仍停止所有生成。

原硅基流动协议仍保留，改为每次1张。更换服务要同步更新或清除旧密钥；主人通过私聊更换地址、模型、接口类型会清除旧自定义价格，避免沿用错误报价，需在后台重新核实保存。后台直接改服务时须同步核对每张最高总价。ComfyUI等原生接口如不兼容，仍需网关。

URL图片需能由OneBot访问，Base64返回不依赖共享文件路径。配置查询/修改命令仍仅主人私聊可用：设置AI画图接口类型、设置AI画图接口地址、设置AI画图模型名、设置AI画图密钥、清除AI画图密钥、查看AI画图配置；质量、尺寸和预算在后台设置。

## 备份、故障与验收范围

## QQ内查看帮助

发送“AI画图帮助”查看目录，发送“AI画图帮助 全部”查看完整分主题合并消息，也可发“AI画图帮助 尺寸”等单页查询。每个参数都有写法、可选值、继承规则和可复制示例；无需模型密钥、不调用模型、不占预算。完整文本见[QQ帮助文档](aiimage-qq-help.md)。

接口错误详情：绘图接口返回非2xx状态时，QQ失败消息会显示HTTP状态，以及接口实际提供的原因（error.message）、类型、错误码、参数名和x-request-id请求编号；已有聊天档案同步保留该脱敏回执。错误正文最多读取64KiB，原因最多600字符，其余字段限长。配置密钥、完整提示词回显、图片数据、链接和CQ控制段会过滤；不保存或转发原始错误正文。空响应、HTML或无法解析的错误会明确提示没有可读取的结构化详情。不会自动重试，预算预留规则不变。此前已被丢弃的错误详情无法补回。

数字错误码保持JSON原文精度；详细过滤范围、局限及本次交付见[错误回执收敛](image-error-delivery.md)。
