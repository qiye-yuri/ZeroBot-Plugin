# 角色卡核对与上传

## 范围

基于PR #70合并后的master `5cd9ff84`，仅整理用户要求的角色卡：按机器人保存人物设定快照、预览并复制到群/私聊、配置字段和后台保护，以及相关测试、使用说明。不包含主动接话、群日记、绘图/GIF、实际额度、摸鱼找鸡或更新监控。

本批产品实现与原工作区对应角色卡改动一致，未发现需修改的阻断问题；额外补充了边界回归。公共AI设置排除角色卡正文并禁止直接写入角色卡字段，卡片操作沿用专用人物接口的权限、配置修订和写前备份。原工作区及暂存内容保持。

## 使用和兼容性

入口及步骤见[保存和复用角色卡](conversation-persona.md#保存和复用角色卡)。仅登录后台后可操作，来源与目标须为同一机器人的会话；卡片保存的是人物设定和性别，不共享档案或记忆。旧配置没有PersonaCards字段时按空卡库处理，不迁移人物设置或改变现有会话。

首次安装功能需要常规备份升级和重启；之后保存、套用立即供新Agent任务使用，无需重启。进行中的任务保留开始时的人物；保存卡片不改变来源会话，目标修改不回写卡片。失败不覆盖配置、不自动重试、不调用模型。
