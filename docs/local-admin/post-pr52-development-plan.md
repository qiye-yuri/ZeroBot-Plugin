## 1 目标与边界

现有任务视图已显示匹配范围和全窗口的已知输出小计，但查找部分缺失或全部未知的任务仍需逐组展开比对。下一批增加“输出用量已知情况”筛选，帮助区分窗口内输出字段全部、部分或完全没有有效值的组。

直接使用现有g.totals.output.known和g.count，不重新扫描usage、不重新判断原始字段、不用输出合计是否为0判断完整性。有效输出0计为已知；已知情况只描述当前窗口输出字段，不代表输入/缓存完整、服务成功、任务完整或费用已核实。

本批是一个功能，三个状态不拆成多个QQ验收项。不增加输入/缓存已知情况筛选、费用占比、历史补查、关联修复、后端参数、持久化或报告字段。历史预算900000及[其他待验收和暂缓项](remaining-acceptance.md)保持。

## 2 操作及分类契约

计划入口：登录后台 → 运行概览 → 模型接口请求 → AI费用风险提示 → 按任务查看用量。沿用后台登录权限，实施并构建部署后刷新页面生效，无保存动作。本轮只加规划入口，不把计划选项写成当前可用功能。

新增原生select，标签“输出用量已知情况”，ID为model-task-output-coverage，位于“请求关联类型”之后、“任务排序”之前，默认all、初始disabled。

| 值 | 显示文字 | 匹配规则 |
| --- | --- | --- |
| all | 全部已知情况 | 默认保留全部分组 |
| complete | 输出全部已知 | known === count |
| partial | 输出部分已知 | known > 0 且 known < count |
| unknown | 输出全部未知 | known === 0 |

分组由已有modelTaskUsage生成，非空组count始终大于0，不为不存在的空组添加兜底或分类。known只计算非负安全整数输出值；缺失、负数、小数、字符串和不安全单值已由上游规则作为未知处理，筛选器不重复执行该验证。多个有效输出相加超过Number安全范围仍是已知，沿用现有BigInt小计。

五类条件按组取交集：风险、请求结果、次数、关联类型、输出已知情况，随后执行现有五种排序。风险与结果可能由组内不同请求命中，仍保留匹配整组；不得先删掉未知请求再分组或计算小计。独立请求逐条成组，只会全部已知或全部未知；独立请求+部分已知没有匹配是正常结果，不自动更改其他条件、不禁用组合或增加弹窗。

匹配组数X/Y、请求覆盖N/M和匹配输出小计随筛选变化；Y/M和全窗口输出小计始终取同一完整快照。全未知筛选命中非空组时，匹配小计显示未知、已知0/N次；无匹配则未知、已知0/0次。有效空窗口、无效窗口沿用既有提示。补一条简短说明：“仅按当前窗口输出字段的已知次数筛选；已知0仍算已知，不代表任务完整或成功。”

### 固定样例

A为有效关联组，输出10、未知；B为有效关联组，输出0；C为独立请求，输出20；D为独立请求，输出未知。共4组5次，已知输出30 Token、已知3/5次。

| 条件 | 匹配组/请求 | 匹配输出小计 | 全窗口小计 |
| --- | --- | --- | --- |
| all | 4/4组、5/5次 | 30 Token，已知3/5次 | 30 Token，已知3/5次 |
| complete | B、C：2/4组、2/5次 | 20 Token，已知2/2次 | 保持全窗口值 |
| partial | A：1/4组、2/5次 | 10 Token，已知1/2次 | 保持全窗口值 |
| unknown | D：1/4组、1/5次 | 未知，已知0/1次 | 保持全窗口值 |
| linked + complete | B：1/4组、1/5次 | 0 Token，已知1/1次 | 保持全窗口值 |
| independent + partial | 0/4组、0/5次 | 未知，已知0/0次 | 保持全窗口值 |

A的一条请求命中风险、另一条命中结果时，partial与这些条件交集仍保留两条请求、输出10、已知1/2次。single与partial无匹配，multiple与partial保留A。已知0不应落到unknown。

## 3 生命周期、布局与导出

选项改变仅调用现有renderModelTaskView本地重绘，不增加网络或模型请求。手动/自动刷新保留选项，按新快照重新分类、筛选与排序；仍可见的同键组保留展开和摘要焦点。组从partial变为complete后应从partial结果消失，筛掉再出现默认收起，不新增跨条件展开缓存。

阈值草稿不改变风险交集；应用或恢复默认阈值后重算，输出已知情况选择保持。重置任务视图恢复all及其他默认条件/原始顺序并收起明细，保留草稿与已应用阈值。读取失败清空并禁用控件，恢复后按保留条件重算；有效空窗口允许操作。离页、退出、认证失效和整页刷新按现有流程恢复all，迟到响应不能恢复旧内容；跨启动与256窗口淘汰不沿用旧分类。

完整JSON导出保持整个快照、现有taskBreakdown及version=1，不增加筛选状态或小计字段。固定快照和阈值下，筛选前后除exportedAt外完整报告一致，并用独立校验器检查实际下载。新分类不是对账结论，不能把unknown解释为0输出。

复用model-task-field布局，键盘顺序为风险 → 结果 → 次数 → 关联 → 输出已知情况 → 排序 → 重置。验证320/640/768/1280px明暗主题、最长标签/选项、长整数摘要及焦点边框；只在实际裁剪或溢出时局部调整，不整体改版、不压缩点击区域或隐藏标签。
