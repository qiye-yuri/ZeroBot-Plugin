# 独立ASR语音识别

本批整理既有实现及合成测试。原完整工作区的验证与本次独立发布范围分别记录，见[语音与文档接口交付](voice-document-delivery.md)。

## 入口及原有方式

引用一条QQ语音后发送`ASR`或`独立语音转文字`，群聊需真实@机器人。也支持与命令同一条消息中的单个语音段。私聊引用只允许当前用户发来的语音，群聊只允许本群引用；多条语音或多个引用会拒绝。

原有`语音转文字`、`转文字`、`转写`等命令仍走NapCat的fetch_ptt_text方式，不变更、不自动切换。新ASR失败不会自动调用旧方式重试，旧方式失败也不会自动触发付费ASR。

## 权限与转换

新入口复用AI设置的联网搜索总开关、会话范围和允许角色，使用已保存DeepSeek搜索密钥。现有主AI聊天响应开关仍须允许处理该消息。

从实际语音消息获取文件标识，通过当前NapCat的get_record（out_format=wav）转换，并读取返回的base64音频。不读取返回的本机路径，也不接受消息中的任意路径、音频网址或内嵌文件代替语音ID。

本版统一提交完整16位PCM WAV；不直接提交QQ的SILK/AMR格式，也不直接接收Ogg文件。支持8/16/22.05/24/32/44.1/48 kHz、单声道或双声道。双声道仅识别左声道，结果中明确提示。

上传前核验RIFF长度、fmt/data块、PCM格式、采样率、声道、字节率和数据长度，最大8MiB、最长120秒。过长语音不截断上传，而是提示分段。

## 请求、结果和费用

固定使用DeepSeek官方`/v1/tools/asr`，表单仅file=speech.wav。只上传本次音频，不发送QQ身份、聊天历史或人物设定；转写结果作为纯文本发送，不执行其中命令、不再调用聊天模型。

每条命令最多一次ASR请求，不自动重试。QQ转换最多30秒、ASR HTTP最多90秒、整条流程最多120秒。配置在转换期间变化时停止提交；提交后变化则丢弃迟到结果。识别失败、响应损坏或过大明确报错，空文本显示未识别到可转写内容，不编造转写。

服务端duration_ms作为实际音频时长显示，按时长计费，不计入聊天模型token统计。失败或超时不等于未计费。服务商限制及当前价格见官方ASR文档：https://api-docs.deepseek.com/zh-cn/guides/asr/
