2026-10-17：使用者已明确恢复N3并选择DeepSeek Search。本文替代2026-10-16暂缓时的候选方案；文件名保留以兼容已有引用。基线为R6提交 `f1e2568f`，分支 `codex/deepseek-web-search`，依赖尚未合并的R5/R6，不自动合并或部署。使用步骤见[联网搜索](web-search.md)。

## 1. 已确定的首版范围

只接DeepSeek独立 [Search API](https://api-docs.deepseek.com/zh-cn/api/search/)，每次请求5条标题、链接与摘要，不接Fetch、不取网页正文。每任务最多尝试2次，10秒期限、256 KiB响应上限，每条摘要最多1,600 UTF-8字节。普通聊天、GPT、群总结不自动联网，模型不因搜索切换。

按[官方指南](https://api-docs.deepseek.com/zh-cn/guides/search/)在2026-10-17的价格，成功非空搜索为5元/千次，模型调用另计。首次真实验证仅使用已有官方凭据、一次公开资料搜索，模型和OneBot保持模拟，不向真实QQ发送；账户级5 QPS超限按工具错误处理，不加全局调度器或自动重试。

默认关闭，后台配置独立密钥、全局开关，以及机器人+群/私聊的会话开关和角色。默认仅机器人主人；群管理及普通成员明确选择后才开放。保存不调用外部服务。外发字段仅为模型提交的query、count和need_content，不自动增加原问题、历史、记忆或QQ身份。

## 3. 数据、工具与生效

配置根字段为可选 `WebSearch`：`enabled`、`key`、`scopes`。scope键复用“机器人:会话”，群为正、私聊为负；策略含enabled与roles。专用 `GET/POST /api/ai-search` 只返回当前范围、修订和keyConfigured，不返回key或其他会话。通用AI接口排除WebSearch，写操作不允许绕过专用入口。

工具为 `search_web`，只有必填query，1～128个Unicode字符。固定POST官方地址，请求为query、count=5、need_content=false；不跟随重定向、不抓取返回链接。只取最多5条可展示HTTP(S)来源；不足按实际返回，不补造。状态为ok/empty/error，错误不能变成成功空列表；供应商错误正文不回传。

每个任务创建一次执行器；有效调用在发HTTP前消耗本地额度，失败也占一次。参数或超额拒绝单列，原历史/记忆三次额度独立。结果进入同一任务上下文，最终发送缺少的实际来源由宿主补齐；Agent搜索后直接结束未发送时，宿主直接返回实际结果或工具错误；搜索文本不能提升动作权限或自动写入长期记忆。结果编号仅在本次搜索内使用，引用以URL为准。

保存沿用原配置代次，旧任务在检查点停止。在途搜索最多等本次期限，返回时保存执行次数，再检查停止/代次；停止后不接纳正文、不继续模型或发送。旧任务缺少WebSearch时不补造零次成功。禁用属于功能回退，数据库恢复属于数据回退，见[维护说明](operations.md)。

## 5. 验收矩阵

| 场景 | 需要核对的结果 | 验证 |
| --- | --- | --- |
| 旧配置/关闭/未授权角色 | 不提供工具，伪造动作拒绝，原流程可用 | SDK、配置及最终程序 |
| 多机器人同号群、群/私聊 | 策略独立、角色不提升、额度不共享 | Go API/执行器 |
| 中文、5条/不足/空结果 | 请求只有3字段，URL对应，不补造 | 模拟HTTP及两轮Agent |
| HTTP错误/超时/超大响应 | 明确工具错误，不重试、不回显原文 | HTTP模拟 |
| 第三次搜索/非法附加范围 | 无额外请求，独立于本地查询 | Go及最终程序 |
| 停止/代次变更返回 | 记录尝试但不装入结果，不继续动作 | 执行门控及原停止回归 |
| 搜索文本含指令 | 工具文本不替代原角色与动作校验 | 权限回归；不声称模型绝不受影响 |
| 保存、撤销、冲突、重启、清除 | 目标冻结，密钥不显示，失败不写库 | Go API/Chrome |
| 最终发送来源 | 来自实际结果，模型省略也补齐 | 两轮Agent、真实Search+模拟平台 |

统一入口：先 `go generate main.go`，再 `pwsh -File scripts/test-agent.ps1 -OutputName zerobot-search-validation.exe`。真实Search复验命令见[使用说明](web-search.md#开发复验)。原始请求、回复、凭据、日志和截图留在忽略的 `.local/`，公开文档仅记范围与结果；模拟验收不能替代真实QQ或真实模型引用质量。
