## 档案查询与 Agent 检索

所有查询使用 `botId + conversationType + conversationId`。HTTP 层接受群或私聊类型及正整数字符串，服务端转换现有会话键。ID 和序号以字符串传输，避免 JavaScript 整数精度损失。机器人必须来自服务端已知账号集合，禁止任意文件名查库。

首次读取固定最大序号为快照边界，后续按序号游标翻页；刷新才进入新快照，每页 50 条。列表显示时间、类型和脱敏正文，消息中的发言者可按已保存字段核对，详情按需读取；消息作为纯文本渲染，图片及附件不自动请求外部资源。

初版采用参数化文本搜索，不依赖尚未验证的中文全文分词。关键词最多 128 个字符；单次最多扫描该范围最近 5,000 条，最多返回 20 个片段；单片段最多 2,000 UTF-8 字节，总量最多 16 KiB，在完整字符边界截断。查询需支持超时和取消。未覆盖完整档案时显示“仅搜索最近部分记录”，零结果不能解释为全部历史不存在。后续有实际召回需求时再评估全文索引。

索引优先复用 `(conversation, seq)`，新增索引由合成大档案的查询计划决定。使用 10 万条合成记录验证读取上限、取消及分页，记录测试机器和耗时，不预先宣称生产性能。

已实现本地 `search_history/read_history/search_memory/read_memory`，搜索支持关键词、来源编号、时间、发言者或事件类型等各工具允许的条件，具体参数见使用说明。机器人、当前会话、角色、最近重置边界由执行上下文注入，不能让模型自行指定。动作先校验权限，绝不转发为 OneBot API。每任务共享最多 3 次历史/记忆查询，纳入同一模型输入预算；不另加固定行动轮数，保留现有重复动作停止机制。

返回来源序号、时间、发言者和节选。Agent 回答需区分引用与推断，冲突资料说明冲突，未找到则明确未找到。历史文本属于资料，不能提升角色权限或授权动作。默认不检索最近重置之前的记录；后台所有者可手动查看归档，但查看行为不使其重新进入模型上下文。

## 长期记忆与迁移

已在每机器人档案数据库新增记忆及修订表，保存记忆 ID、会话键、正文、来源类型、来源记录序号、有效状态、修订号和创建更新时间。来源类型区分 Agent、后台及旧文件导入，不从模型文本推断用户明确要求；来源未知时明确标识，不补造事件。

新增记忆沿用现有动作白名单，只落入当前机器人当前会话。后台密码持有者可修订、停用和恢复；保存必须带修订号，并发冲突要求重新读取。旧版本保留，停用后不进入后续模型请求。初版不提供物理删除，页面说明停用不等于清除磁盘记录。

旧文件迁移按以下顺序实施：

1. 盘点 `data/aichat/agent/<会话编号>.txt`，由后台所有者选择归属机器人，预览会话、条数和冲突。多个机器人存在同号会话时不得自动分配。
2. 锁定受影响会话的记忆写入，备份原文件，核对预览时的来源摘要。
3. 单事务导入并记录来源摘要和迁移版本；同一来源重复提交不得重复导入。失败回滚数据库，原文件保持可用。
4. 已迁移范围只写新库，不隐式双写；未分配范围暂沿用旧逻辑并标明“未迁移”，不宣称已隔离。新存储全面启用以归属处理完成为条件，首阶段档案入口不展示旧记忆。

旧程序不会读取新记忆表，回退程序后新增记忆不会自动可用。回退前停止服务，保存数据库与旧文件的一致副本；需要旧格式时单独导出指定机器人和会话，处理同号冲突。启用前须显示此限制，不能以程序回退冒充数据已恢复。

## 任务状态与停止语义

任务键包含进程实例、机器人、会话及随机任务 ID。采用 `running → cancel_requested → cancelled`；正常结束为 `completed`，异常为 `failed`，重启遗留任务为 `interrupted`。终态不可再改变；终态落盘失败不得显示已可靠保存。

同一机器人同一会话只运行一个 Agent 任务，新触发返回忙状态，不排无限队列；不同会话独立。模型请求与每个动作派发前检查取消和设定代次。当前采用“等待在途模型/识图或平台请求返回后停止”，准备期间在当前下载/识图返回后检查，不继续后续准备或派发；界面不宣称即时中断。

取消不撤回已发 QQ 消息或逆转已执行的群操作。在途 OneBot 请求记录最终回执，但不再派发后续动作；丢失回执记为结果未知，不自动重发。取消携带任务 ID 和版本，重复取消幂等，旧请求不能停止新任务。

初版取消仅供已登录后台所有者使用，不新增 QQ 角色授权。任务页显示阶段、动作名称、起止时间、停止状态和脱敏错误类别，不显示模型内部思考。现有统计口径保持，任务数、模型调用数和发送数不能强求相等。

## 已实现接口与设计基线

下表列出阶段接口，具体参数和收敛范围以各使用文档为准。读接口均要求后台认证，POST 同时校验来源和 CSRF；聊天数据响应使用 `Cache-Control: no-store`。

| 方法与路径 | 用途 | 关键约束 |
| --- | --- | --- |
| `GET /api/agent/conversations` | 指定机器人会话列表 | 有界分页，只返回元数据 |
| `GET /api/agent/history` | 档案分页或单条详情 | 完整范围、固定快照、游标绑定范围 |
| `POST /api/agent/history/search` | 文本搜索 | 关键词在请求体，限流、超时和截断标记 |
| `GET /api/agent/memories` | 记忆及修订 | 完整范围，区分未迁移与空列表 |
| `GET /api/agent/memories/current` | 按编号定位当前管理条目 | 包含停用，当前机器人和会话 |
| `GET /api/agent/memories/revision` | 精确历史修订 | 同一记忆及修订号，只读不变更当前条目 |
| `GET /api/agent/memories/read` | 启用当前版本正文 | 旧修订或停用不返回正文 |
| `POST /api/agent/memories/search` | 当前记忆检索 | 状态/来源/时间条件、有界扫描及继续位置 |
| `POST /api/agent/memories/create` | 后台录入 | 独立记忆模式、同文复用及明确回执 |
| `POST /api/agent/memories/update` | 修改、停用和恢复 | ID、版本、固定操作，无任意文件或 SQL |
| `POST /api/agent/memories/migration-preview` | 旧记忆预览 | 来源、归属、摘要、有效期 |
| `POST /api/agent/memories/migrate` | 确认导入 | 一次性票据、摘要复核、备份及幂等 |
| `GET /api/agent/tasks` | 范围内任务 | 有界结果、版本及状态 |
| `GET /api/agent/tasks/read` | 单条当前任务摘要 | 按已加载范围与任务编号，只读不取消 |
| `POST /api/agent/tasks/cancel` | 请求停止 | 完整范围、任务 ID、版本及幂等 |

错误区分参数错误 400、未认证 401、无权访问 403、不存在 404、版本或状态冲突 409、限流 429、存储不可用 503，不包含聊天、密钥或本机路径。取消已结束任务返回现有终态，未知任务返回不存在。

切换范围、退出或会话过期时清空历史内容与搜索输入。异步结果绑定登录代次和已加载范围，旧响应不覆盖新会话。读取失败可保留同范围旧结果，但标记未更新，禁止基于过期版本写入。
