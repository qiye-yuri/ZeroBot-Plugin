# 独立TTS语音合成

本批整理既有实现及合成测试。原完整工作区的验证与本次独立发布范围分别记录，见[语音与文档接口交付](voice-document-delivery.md)。

## 使用

- `TTS 要朗读的文字`：默认海星女声stella。
- `TTS女声 要朗读的文字`：海星女声stella。
- `TTS男声 要朗读的文字`：暗潮男声tide。
- `独立语音 要朗读的文字`：默认女声。

群聊需真实@机器人，私聊直接发送命令。仅发送至当前群或当前私聊，不允许指定其他收件人。复用AI设置中的联网搜索总开关、会话范围、允许角色及已保存DeepSeek搜索密钥；主AI聊天响应开关仍须允许处理。

原来的“发送AI语音”、QQ音色选择和聊天自动QQ语音回复保持原方式。本入口只朗读用户明确给出的文字，不自动接管聊天回复；失败也不切换至其他语音方式，不调用聊天模型。

## 音频与边界

使用DeepSeek独立`/v1/tools/tts`整段合成，format=pcm、filter_markdown=true。HTTP完整读完后，将官方约定的24kHz、16位、单声道PCM包装为WAV，再以语音消息发送。读取错误、格式不符、空数据、奇数字节、长度不符或音频超过120秒时不发送。

每次最多1000计费字符（汉字按2个，其他Unicode字符按1个进行本地预检查）；音频最大120秒。音频长度是在合成后检查，超限不发送仍可能产生服务商费用。合成最长等待120秒，发送回执最多等待30秒。暂不提供语速调节、实时分段播放或续传。

合成及发送各最多一次，不自动重试；发送失败或未返回有效非零整数消息ID时提示先检查是否已收到，避免重复发送。

只上传本次朗读文字及音色参数，不附带QQ身份、人物设定或聊天历史。音频只在内存处理，不新增本机音频文件。使用语音段发送，不把朗读文本当作OneBot动作执行。

## 费用

TTS按文本字符计费，不计入聊天模型token统计；本地字符计数为提交前限制，不是服务商账单。当前尚未验证真实金额和音质。
