# AI 基础配置检查

R6基础摘要分别检查聊天、GPT、群总结、Agent及识图五个入口；GPT/群总结按保存的独立引用或聊天继承解析。命名模型表单同时显示实际选择与继承来源。字段检查不证明群总结权限、触发条件或模型可用性，实际调用仍需显式诊断，见[独立入口](r6-model-routes.md)。下文原三入口检查及历史验收按当次范围保留。

包含 R5 的构建可在[命名模型卡片](named-models.md)逐项查看最大输出长度、TopP 与推理设置的来源和有效值。参数范围在保存时检查；字段完整不代表提供商支持该参数。基础检查仍不调用模型，不验证温度、动作权限或实际触发条件。

基础字段检查仍不请求模型。实际网络、凭据和协议核对可在同页显式点击“测试聊天模型”或“测试 Agent 模型”；每次可能消耗额度，只使用已保存入口，不执行 Agent 动作。步骤与限制见[手动模型测试](model-probe.md)。

启用[命名模型配置](named-models.md)后，摘要检查五个入口实际选择的配置；Agent/识图未选择时表示该入口停用。命名配置的识图条目需要模型名；下文“识图模型名可留空”仅描述旧字段模式。摘要仍不发起模型请求。

登录本机后台，进入“AI 设置”，在表单上方查看“AI 配置检查”。分别显示聊天、GPT、群总结、Agent、识图的接口类型、模型名、接口地址和密钥是否填写；读取的全局配置包含程序默认值。GPT与群总结按对应选择或聊天继承解析，Agent使用自己的接口和密钥；识图是可选配置。

检查接口类型是否支持，以及地址是否满足当前保存规则（完整HTTP/HTTPS、有效端口、不含URL认证参数）；地址值、模型名、密钥内容不进入摘要。遗留地址含隐藏认证参数时提示需检查，原配置仍保留、不自动修复。OLLaMA接口允许无密钥，OpenAI/GenAI需要独立密钥；识图模型名可留空，需按接口要求核对。

“基础字段检查通过”仅表示以上字段满足本机检查条件，不验证密钥有效性、模型是否存在、余额、网络连接、工具调用或图片能力。识图未配置不阻止文字聊天。Agent还取决于已读取会话的模式、插件开关、响应规则、@和权限；/gpt使用GPT入口，未选择时继承聊天接口。真实模型和QQ业务联调见原待办。

摘要在成功读取AI设置或保存全局模型后更新。未保存字段/密钥动作、群号或私聊QQ输入、会话参数草稿和放弃操作不会改变检查结果；会话参数保存也不覆盖全局草稿或摘要。读取/保存失败保留最近成功结果并显示错误，重新加载需按原规则确认放弃草稿；退出或会话过期清空，旧请求不能回填。未接入配置插件或旧版接口无检查结果时提示不可读取，不自行推断“通过”。

本页检查只读，不另发模型请求，不花费模型调用额度、不创建配置备份、不改变原聊天/Agent/识图行为。编辑和保存仍走原确认、版本冲突与写前备份流程。

验收：刷新AI页核对已保存的聊天/GPT与Agent基础状态，以及未配置的可选识图。编辑模型名或密钥动作但不保存，摘要应保持；放弃草稿后仍显示原结果。无需为验收清除日常密钥；缺项、地址和失败组合使用隔离配置验证。
