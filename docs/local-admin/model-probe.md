# 后台手动模型测试

R6增加“测试 GPT 模型”和“测试群总结模型”，分别解析对应独立引用，未设置时继承聊天模型。与聊天、Agent按钮共用一次在途请求限制；只做基础文字调用，不读取群历史、执行群总结或QQ收发。设置见[独立入口说明](r6-model-routes.md)。

R5 参数规则：诊断的最大输出长度固定为 128，不采用业务模型的长度覆盖；TopP、推理设置按所选命名配置逐项覆盖或继承全局。温度仍为诊断固定值 0.2，不使用会话温度。自定义空推理设置与继承不同；协议实际支持范围沿用原适配。设置方法见[命名模型](named-models.md)，不会因读取或修改参数草稿自动测试。

R3已随R1～R4合并master并部署到本机日常服务，原配置保持；重新登录后台即可使用。部署后两个实际按钮均成功调用真实提供商，草稿、统计与修订保持，见[部署验证](self-test.md#r1-r4-合并与日常部署验证)。此前旧/命名模式、历史结果、旧修订409及离页清除的实际验证见[实机记录](self-test.md#r1-r4-实机测试进度)。

登录后台进入“AI 设置”，先读取已保存配置，在“手动模型测试”点击对应的聊天、GPT、群总结或 Agent 测试按钮。每次点击会向该入口的提供商发出一条固定短文字请求，可能消耗额度；配置读取、保存和页面帮助不会自动测试。

测试使用服务端已保存配置及页面读取的修订号，不使用未保存的地址、密钥或提示词。命名模式按入口引用解析，旧模式沿用原字段；入口停用、配置不完整或版本变化时，在请求前提示处理。请保存所需配置并重新读取后再测试。

成功表示本次返回了可解析的非空文字。Agent 入口也仅验证基础文字调用，不运行工具或平台动作；识图、完整 Agent 和 QQ 收发请使用[真实模型测试](real-model-test.md)。结果不展示提供商正文或密钥，不承诺下次请求一定成功。

结果卡片显示入口、脱敏模型标识、测试配置版本、时间和耗时。重新读取或保存后发现配置修订变化时，旧结果标为历史结果；编辑草稿不会改变测试目标。结果仅保留当前页面，离开 AI 页面、退出或登录失效时清除，迟到响应不会恢复旧结果。

每个后台实例同时只运行一个测试；其他窗口也须等待。没有自动重试、失败换模型或自动保存。请求期限为 30 秒，响应上限 256 KiB；切页清除结果不代表外部请求或费用已撤销。在途请求按既定期限结束。

诊断请求不计入概览四类业务模型统计，不创建配置备份或修改会话、档案与记忆。接口为 `POST /api/ai-test`，需要后台登录、来源和 CSRF 校验；请求只包含 `entry`（chat/gpt/summary/agent）及 `revision`，不接受自由提示词、地址或密钥。运行包含此功能的新构建后生效，部署与验收状态见[自测](self-test.md)。

接口验证/版本/并发错误分别使用 400、409、429，未登录或 CSRF 错误沿用 401/403。实际调用结束返回 200，并以 `success`、`category` 和说明区分通过、网络/超时、提供商 HTTP 拒绝、响应格式与容量失败；提供商返回 401 不会冒充后台登录过期。


R9 增加[搜索密钥诊断](search-probe.md)，与本页四个模型入口共用一个在途名额；任一测试进行时，其他测试按钮暂不可用，后台同时拒绝并发测试（429），不排队或自动重试。搜索测试使用独立已保存搜索密钥，最多10秒，不运行模型。


## 诊断结果读法（R12）

R12已实现，尚未合并部署。运行包含R12的程序并刷新后台后，使用原后台密码登录并进入AI设置，按原步骤读取已保存配置，再显式点击相应测试按钮。每次测试仍可能消耗提供商额度，未保存草稿不参与。

结果先显示入口与结论，再显示服务端说明、测试时间、耗时和已有HTTP状态；模型结果包含模型名称，搜索结果包含合法结果数。搜索无匹配结果与失败分开显示；未取得HTTP状态时不显示HTTP编号。基础调用通过不保证后续调用、完整Agent动作或QQ收发成功，搜索诊断也不会启用会话搜索。

完整修订号移至“完整测试配置修订（展开核对或复制）”，新结果默认收起。点击标题或Tab聚焦后按Enter展开/收起，展开后可选择并复制完整编号。展开只显示本页已有内容，不发请求。按钮状态更新不收起当前展开内容；重新测试产生新结果时默认收起，重新读取搜索表单重建结果区时也默认收起。

当前版本/历史结果提示在折叠区外始终可见。保存或重读配置导致修订变化时，旧结果标为历史结果；编辑未保存草稿不会伪造新测试版本。模型与搜索各保留自己的结果，沿用共享在途限制。离开AI页面、退出或登录失效清理结果，迟到响应不重新显示；结果不持久化。
