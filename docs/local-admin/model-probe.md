# 后台手动模型测试

R3已随R1～R4合并master并部署到本机日常服务，原配置保持；重新登录后台即可使用。部署后两个实际按钮均成功调用真实提供商，草稿、统计与修订保持，见[部署验证](self-test.md#r1-r4-合并与日常部署验证)。此前旧/命名模式、历史结果、旧修订409及离页清除的实际验证见[实机记录](self-test.md#r1-r4-实机测试进度)。

登录后台进入“AI 设置”，先读取已保存配置，在“手动模型测试”点击“测试聊天模型”或“测试 Agent 模型”。每次点击会向该入口的提供商发出一条固定短文字请求，可能消耗额度；配置读取、保存和页面帮助不会自动测试。

测试使用服务端已保存配置及页面读取的修订号，不使用未保存的地址、密钥或提示词。命名模式按入口引用解析，旧模式沿用原字段；入口停用、配置不完整或版本变化时，在请求前提示处理。请保存所需配置并重新读取后再测试。

成功表示本次返回了可解析的非空文字。Agent 入口也仅验证基础文字调用，不运行工具或平台动作；识图、完整 Agent 和 QQ 收发请使用[真实模型测试](real-model-test.md)。结果不展示提供商正文或密钥，不承诺下次请求一定成功。

结果卡片显示入口、脱敏模型标识、测试配置版本、时间和耗时。重新读取或保存后发现配置修订变化时，旧结果标为历史结果；编辑草稿不会改变测试目标。结果仅保留当前页面，离开 AI 页面、退出或登录失效时清除，迟到响应不会恢复旧结果。

每个后台实例同时只运行一个测试；其他窗口也须等待。没有自动重试、失败换模型或自动保存。请求期限为 30 秒，响应上限 256 KiB；切页清除结果不代表外部请求或费用已撤销。在途请求按既定期限结束。

诊断请求不计入概览四类业务模型统计，不创建配置备份或修改会话、档案与记忆。接口为 `POST /api/ai-test`，需要后台登录、来源和 CSRF 校验；请求只包含 `entry`（chat/agent）及 `revision`，不接受自由提示词、地址或密钥。运行包含此功能的新构建后生效，部署与验收状态见[自测](self-test.md)。

接口验证/版本/并发错误分别使用 400、409、429，未登录或 CSRF 错误沿用 401/403。实际调用结束返回 200，并以 `success`、`category` 和说明区分通过、网络/超时、提供商 HTTP 拒绝、响应格式与容量失败；提供商返回 401 不会冒充后台登录过期。
