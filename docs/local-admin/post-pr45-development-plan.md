# PR45后的详细开发计划：包含任意用量提示的任务筛选

核对日期：2026-10-27（Asia/Shanghai）。基线master `c99b9e2adb60275650ee43629c31d50e37f89f95`。PR #45已完成部署验收及合入，见[最终清单](task-risk-counts-acceptance.md)。本次仅交付设计；下述选项尚未实现，不表示已上线。

## 1 问题与目标

任务摘要已经显示四类可重叠用量提示，但当前风险筛选只有全部、大输入、高未命中、字段不完整/不一致。用户要检查所有有提示的任务，需要轮流切换多个条件，并自行辨认重复任务。

下一批在现有风险下拉框增加“包含任意用量提示”，一次保留至少有一条请求命中任一现有提示的任务。它是四类判定的并集，不是新增风险等级，不判断任务失败、费用或预算。

源码依据：[index.html](../../internal/localadmin/assets/index.html)中的model-task-filter定义上述四个选项；[overview.js](../../internal/localadmin/assets/overview.js)中的selectModelTaskGroups负责任务级筛选，modelRequestRisk返回large、highMiss、incomplete、inconsistent。摘要和逐请求原因已经复用同一判定，可直接复用，不增加采集或后端。

历史预算900000、[其他待验收和暂缓项](remaining-acceptance.md)保持原状。本批不处理其他插件或真实业务缺口。

## 2 交互与数据契约

入口仍为“运行概览 → 模型接口请求 → AI费用风险提示 → 按任务查看用量”，需要既有后台登录，无额外权限或保存配置。

在“全部任务”后增加一个原生option，显示“包含任意用量提示”，内部值anyRisk；其后保留原有选项及值large、highMiss、invalid。默认仍为all。不增加新控件、图标、颜色等级、计数徽标或按钮，不改变Tab顺序。

### 筛选规则

一个任务满足条件，当且仅当该组当前窗口至少一条请求的modelRequestRisk在large、highMiss、incomplete、inconsistent中有任一true。所有请求都没有提示时排除；同请求命中多类或同组多次命中只保留一个任务，不重复展示。

筛选依据请求判定，不解析摘要中文、不累计四类计数后作另一套判断，不把组内输入小计与单次阈值比较。输出缺失但输入已知仍按现有规则判定；未知不补零，缓存不一致不等同模型调用失败。

风险条件与“任务包含的请求结果”继续在任务级取交集，两条件可以由不同请求命中。例：同组第一条为大输入且接口完成，第二条为普通输入且失败，选择“包含任意用量提示”与“包含失败请求”仍保留整组。只有失败但没有用量提示的任务不匹配anyRisk。

筛选仅决定整组是否显示，不裁剪组内请求。摘要结果分布、四类提示计数、Token小计与展开正文仍覆盖完整窗口内该组请求。独立请求只判断自身，跨会话不串组；重复id、不完整关联标识及最多256条窗口语义保持现有行为。

### 阈值与状态

按已应用设置计算，编辑草稿不更新筛选；应用有效设置或恢复默认后，用现有快照立即重算筛选、摘要和正文，不增加网络或模型请求。无效设置不改变已应用结果。

仍可见同键任务保持展开和摘要焦点；因新阈值被筛掉后返回的任务默认收起。排序仅排列匹配组，稳定顺序和未知末尾规则保持。重置任务视图恢复all/all/original并收起明细，保留已应用阈值及草稿。

同页刷新保留anyRisk选择并使用新快照；跨启动不继承旧展开状态。读取失败清空内容并禁用控件，恢复后按现有保留选择计算；离页、退出及认证失效恢复all。空窗口、无匹配和数据未知保持不同说明，不生成虚构任务或把未知写成零。

完整导出仍包含全部窗口数据，不受筛选或排序影响。version=1、requests、taskBreakdown和thresholds及既有hints格式保持，不新增筛选条件字段，也不修改独立报告校验器。

合成夹具至少包含：普通完整请求、大输入且高未命中的请求、只有字段缺失的请求、缓存分项不一致的请求，以及同组一条有提示且完成/另一条无提示且失败。另设两个小输入累计超过阈值但单次不超过、跨会话同任务、独立项、重复id、截断前后样本。验证每类独立可命中，不只测同时命中多类的样本；未知和异常值沿用既有规则，不新增兼容分支。

浏览器检查实际可见文本、选中值、组列表、展开状态与几何边界；不能只断言源码出现anyRisk。验证同组计数没有随筛选被裁剪。下载通过实际浏览器触发，独立工具校验，不以函数返回值代替下载链路。测试覆盖行为差异，不为每行实现新增镜像断言。

### 非空验收步骤

1. 部署后优先复用自然请求，确认统计起点属于本批程序。没有样本时只在[约定空闲时段](../../AGENTS.md#真实模型测试时间与费用约束2026-10-23)请用户发送一次简短请求并确认收到；不自行代发、不复用前批截图。
2. 对字段完整、默认无提示的真实样本，选择anyRisk应无匹配；导出仍保留完整请求。若自然样本本身有提示，按实际判定记录，不强行制造无匹配。
3. 在页面把大输入阈值草稿设为1，先确认草稿不改变匹配；应用后，只有已知输入满足阈值的组应出现。核对摘要计数、正文原因和结果筛选，操作不产生模型请求或修改历史预算。
4. 下载报告并独立校验。保持同一阈值时，对比切换anyRisk前后完整requests、taskBreakdown及thresholds不变；应用阈值前后允许原有thresholds/hints变化，不能误判为报告格式变更。
5. 恢复默认提示与默认任务视图，确认页面恢复；保留最小证据，核对哈希后清理本批下载副本。

真实样本只有一组时，多组并集、混合结果和异常字段保留自动化证据，不声称全部真实分支通过。不为覆盖而发大输入、失败请求或篡改真实数据。
