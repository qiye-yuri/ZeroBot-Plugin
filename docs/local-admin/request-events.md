# 好友申请与群邀请（P038）

插件 `event` 将好友申请和邀请机器人进群的通知发给配置中的第一位主人。通知中的合并消息以机器人身份展示。

主人在机器人私聊使用：

| 命令 | 作用 |
| --- | --- |
| 查看申请处理设置 | 只查询三个自动处理开关 |
| 开启自动同意申请 / 关闭自动同意申请 | 控制是否自动通过所有好友申请 |
| 开启自动同意邀请 / 关闭自动同意邀请 | 控制是否自动接受所有入群邀请 |
| 开启自动同意主人 / 关闭自动同意主人 | 控制是否自动接受主人发起的上述请求 |
| 同意申请flag / 拒绝申请flag | 处理通知中的好友申请 |
| 同意邀请flag / 拒绝邀请flag | 处理通知中的群邀请 |

把 `flag` 替换为通知给出的完整内容，不保留占位文字。好友标识以 `f_` 开头，邀请标识以 `g_` 开头；不要混用。标识后可以空格追加好友备注或拒绝邀请的理由。旧版四字标识仍可解析，但旧版已截断的长标识无法恢复，需要使用新通知。

设置沿用第一位主人的全局存储，所有主人共用，保存后立即生效并在重启后保留。默认关闭普通申请和邀请的自动通过，默认开启主人请求的自动通过；已有设置不会被升级重置。关闭“自动同意主人”只取消该特殊通道，若普通申请或邀请自动通过仍开启，主人也会按对应普通开关处理。

只有主人私聊可以修改或手动处理；群内和普通用户不能使用这些管理命令。未配置主人时不处理申请。插件总开关关闭后不响应。只在 OneBot 返回成功时确认“已同意/拒绝”；失败会提示未确认成功，自动处理失败还会附上重试命令。实际是否仍能处理取决于 QQ 申请是否有效、是否已在其他客户端处理。

真实申请验收需要另一个账号或尚未加入的授权测试群。无需为验收删除现有好友或退出当前群。隔离模拟通过不代表真实加好友、进群已经验收。
