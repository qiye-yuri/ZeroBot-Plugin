# 独立OCR图片转文字

本批整理既有实现及合成测试。原完整工作区的验证与本次独立发布范围分别记录，见[语音与文档接口交付](voice-document-delivery.md)。

## 使用

私聊发送一张图片并配文`OCR`或`图片转文字`；也可引用一条只含一张图片的消息后发送命令。群聊需真实@机器人。没有明确命令、未@的群消息不会触发OCR，也不会把OCR结果交给聊天模型总结或执行。

本版支持PNG、JPEG和WebP单张图片，最大8 MiB，单边不超过8192像素，总像素不超过1600万。PDF、Office、GIF和批量图片入口暂未接入。请使用QQ图片附件，不接受任意网址、本机路径或文件名作为命令参数。引用仅允许本群消息，私聊仅允许当前用户发送的消息。

## 权限与配置

复用AI设置的联网搜索总开关、机器人/群或私聊范围、允许角色，使用已保存的DeepSeek搜索密钥。现有主AI插件及会话响应设置仍须允许该消息进入处理；不另开后台设置，不自动启用任何权限。

识别固定调用DeepSeek官方`/v1/tools/ocr`，上传字段仅file与purpose=text_recognition。仅发送图片字节及通用文件名，不发送QQ身份、人物设定或聊天历史。图片下载不附带API密钥，且仅允许QQ图片域名，拒绝重定向和任意本机文件读取。附件只在内存处理，不新增持久化图片副本。

## 输出和费用边界

按页展示原始识别文本，保留OCR位置/版面标记。空白页显示未识别到文字；服务端length状态明确标为不完整；超过12000字只显示前12000字并提示裁图后分次识别。结果作为纯文本消息发送，不解析为CQ动作。

一次命令最多一次OCR请求，不自动重试。整体超时180秒，图片下载最多15秒，OCR响应上限2 MiB。HTTP错误、HTTP 200中的error对象、无效页数及页面状态分别按失败处理。

OCR按服务商成功识别页数计费，响应中的token仅供参考；它不进入现有聊天模型token费用统计。超时或客户端断开不保证服务端取消识别，因此不自动重试。本批未新增真实费用核验；已有独立接口验证的范围见交付记录。
