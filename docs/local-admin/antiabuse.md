# 本地违禁词

P001 `antiabuse`仅在群聊检测当前群的词表。管理员或机器人主人可维护词条：

- `添加违禁词测试词`：新增一个按字面匹配的词条。空词拒绝，重复添加不会新增副本。
- `删除违禁词测试词`：精确删除该词，引号和分号按普通字符处理。
- `查看违禁词`：群成员可查看当前群词表图片；空列表显示`[]`。

词表按群隔离，私聊不检测。消息包含词条时，插件尝试撤回消息、禁言发言者两分钟，并通过框架屏蔽该账号两分钟（屏蔽范围跨会话）。检测会忽略消息中的换行和制表符，不是正则匹配。QQ禁言和撤回能否执行取决于机器人权限、对方身份和平台限制；机器人不能禁言群主或权限更高的成员。

重启后按记录剩余时间恢复屏蔽，不会仅因剩余不足一分钟就提前解除。历史空词不再参与匹配和展示，避免误命中所有消息。关闭当前群antiabuse停止新的检测，但不会撤销已经产生的QQ禁言或尚未到期的框架屏蔽。

实机验收只维护合成词条，添加后查看，再立即删除并确认消失。不要用机器人主人账号直接触发词条验证封禁；处罚动作先以隔离模拟群成员验证，真实普通成员测试另行安排。不要在同一群已有词条上做删除测试。
