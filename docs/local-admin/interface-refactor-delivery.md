## 范围

基线为master的20628ba6。本批统一链接阅读与深度搜索的模型入口校验、HTTP鉴权、禁止重定向、超时、用量统计和2MiB响应限长；两个功能各自保留请求参数、90秒/180秒时限、结果核验和失败提示。普通AI、命名模型、搜索和费用查询共用密钥保留/替换/确认清除规则，凭据仍分别保存。

不包含语音、OCR、文档问答、GIF、赠送额度、人物卡、主动接话变更或其他已有未提交功能。运行配置、密钥、数据库、QQ档案、程序、截图和原始证据均不上传。
