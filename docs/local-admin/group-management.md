P007 `manager` 保留禁言、手动撤回、欢迎告别、名片/头衔、精华及原有提醒等功能；完整命令见服务帮助。操作仍要求各命令原有权限，群内实际管理操作还需要机器人具备对应权限。P001本地违禁词和P038好友/群邀请事件处理保留。框架job和群提醒保持现有实现，定时整合暂缓。

## 自动撤回（原P014）

服务列表及后台只显示 `manager`，不再单列 `autowithdraw`。自动撤回有独立开关：

| 命令 | 作用 |
| --- | --- |
| 查看群管功能开关 | 查看当前会话的自动撤回开关 |
| 开启自动撤回 | 在当前会话启用 |
| 关闭自动撤回 | 在当前会话关闭，不影响手动撤回及其他群管功能 |

群内由群管理员、群主或机器人主人修改；私聊可修改自己会话的开关。保存立即生效并跨重启保留。群与私聊分别保存，沿用旧autowithdraw设置；没有旧设置时默认开启。manager总开关关闭时，其下自动撤回也停止；重新启用manager不会重置自动撤回开关。

触发方式：发送一条能触发机器人回复的消息，收到回复后在QQ中撤回自己的原消息。收到QQ撤回通知时，机器人尝试撤回与原消息关联的自身回复。无需发送“撤回一条消息”这句话。仅处理运行期间框架仍保存关联记录的消息；重启前的关联、QQ撤回时限、接口权限或通知缺失可能导致无法撤回，不保证所有历史回复都能删除。

## 欢迎、告别与精华查询

群管理员可发送`测试欢迎语`、`测试告别辞`预览当前设置，未配置时返回默认文案；预览不需要成员真的入群或退群。`设置欢迎语内容`和`设置告别辞内容`会覆盖当前群配置，验收优先只预览，不覆盖已有设置。`/精华列表`查询当前群精华；机器人生成的说明显示机器人身份，引用的真实精华保留原作者。
