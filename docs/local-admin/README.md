任务列表可按最近动作结果筛选，支持等待回执、平台拒绝、结果未知等条件，并与原筛选组合。见[结果筛选说明](agent-tasks.md#按最近动作结果筛选任务)。

记忆版本区支持填写任意两个历史修订号，直接比较正文差异及启停状态，保持只读。见[两次修订对比](agent-memory.md#任意两次历史修订对比)。

可直接粘贴档案来源序号核对单条原文，沿用已加载会话和重置范围，保留时间线及搜索位置。见[来源序号定位](agent-archive.md#按来源序号定位档案)。

任务列表支持按开始时间范围筛选，可与状态、错误类别和阶段组合，翻页沿用已应用条件。见[任务开始时间筛选](agent-tasks.md#按任务开始时间筛选)。

任务列表将较长的取用与执行统计默认收起，点击即可展开；单条核对默认展开，错误和操作入口仍直接可见。见[任务统计展开说明](agent-tasks.md#展开任务取用与执行统计)。

记忆版本区可按修订号直接定位历史版本，保留原列表，复用对比和恢复流程。见[历史修订定位](agent-memory.md#按修订号定位历史版本)。

后台档案搜索可选择每侧 1～3 条前后事件，切换范围后手动重读，仍受原会话及容量限制。见[前后事件范围](agent-archive.md#选择前后事件范围)。

任务列表新增“核对最新状态”，可直接读取所点任务的最新摘要，保留列表筛选与分页；见[任务快捷核对](agent-tasks.md#从任务条目核对最新状态)。

Agent 和后台可按当前记忆的修订时间检索，支持单端时间、来源/关键词组合及实际位置继续；后台另可组合启停状态。见[修订时间检索](agent-memory.md#按当前修订时间检索记忆)。

任务列表可按准备、模型等待、动作在途等阶段筛选，并与状态、错误类别组合；分页保留已应用条件。见[按阶段筛选任务](agent-tasks.md#按阶段筛选任务)。

记忆历史默认从最新修订向前翻页，保留原版本比较和恢复流程；步骤及接口兼容说明见[从最新修订查看版本](agent-memory.md#从最新修订查看版本)。

Agent 与后台历史搜索支持聊天消息、通知和请求类型，也可只按类型检索并沿实际位置继续。使用见[事件类型检索](agent-memory.md#按事件类型检索历史)及[后台操作](agent-archive.md#按事件类型搜索)。

任务摘要新增总耗时、当前阶段持续时间及停止等待的读取快照，使用服务端时间并保留手动刷新。用法见[任务耗时快照](agent-tasks.md#任务耗时快照)。

后台可按启用、停用或全部状态搜索当前记忆，找到停用条目后定位并恢复；步骤见[按启停状态搜索记忆](agent-memory.md#按启停状态搜索记忆)。

Agent 与后台支持仅按具体来源浏览启用记忆，关键词可留空，继续查询保留条件；步骤见[按记忆来源检索](agent-memory.md#按记忆来源检索)。

记忆管理新增[按编号定位当前版本](agent-memory.md#按编号定位当前记忆)，支持从搜索结果跳转并使用现有修订流程。

历史检索支持[只按时间回顾会话](agent-memory.md#只按时间回顾会话)，后台可直接填时间并搜索，保留原继续查询和范围限制。

记忆搜索新增[按来源检索](agent-memory.md#按记忆来源检索)，Agent 和后台共用当前版本来源及继续条件。

发言者搜索支持无关键词查看最近消息：[Agent 用法](agent-memory.md#按发言者检索历史)及[后台入口](agent-archive.md#按发言者搜索)。

Agent 输出新增[JSON 结构上限](agent-tasks.md#json-结构上限)：64 层容器、每轮累计 10,000 个值，超限在保存和派发前整批拒绝。

历史检索新增发言者条件：[Agent 用法](agent-memory.md#按发言者检索历史)与[后台操作](agent-archive.md#按发言者搜索)，明确字段依据、继续条件和未知旧记录限制。

任务查询新增：[按错误类别筛选](agent-tasks.md#按错误类别筛选任务)，支持与状态组合及跨页继续，区分未记录、其他旧类别和已知模型/存储错误。

后台新增：[人工核对前后事件](agent-archive.md#人工核对前后事件)，在当前重置范围搜索结果中展开中心和相邻事件，说明草稿绑定、截断及失败提示。

Agent 新增：[来源上下文核对](agent-memory.md#核对来源的前后事件)，可读中心前后少量事件，说明范围、额度和返回限制。

记忆检索更新：[按实际进度继续检索记忆](agent-memory.md#按实际进度继续检索记忆)说明 Agent 回执、后台按钮、版本状态和额度规则。

后台检索更新：[按实际进度继续搜索](agent-archive.md#按实际进度继续搜索)说明空结果继续、条件保留及失败后重新查询。

检索更新：实际扫描继续位置、空结果继续和返回条数限制见[Agent 继续检索](agent-memory.md#按实际扫描进度继续检索)。

Agent 更新：模型历史检索的时间范围、UTC 回执和额度说明见[历史检索](agent-memory.md#按保存时间检索历史)。

档案更新：按保存时间范围搜索、时区与扫描限制见[会话档案](agent-archive.md#按档案保存时间搜索)。

识图更新：多段纯文本拼接、异常内容跳过及缓存恢复见 [Agent 识图](agent-vision.md)，自动化验证见[自测摘要](self-test.md)。
