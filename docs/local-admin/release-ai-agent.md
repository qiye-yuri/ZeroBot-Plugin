# AI 与 Agent M1～M3 交付说明

2026-10-16：本阶段 AGA-01～07 已完成开发、自动化验证及约定的真实模型和主人私聊复验。此名称表示功能范围，沿用项目已有版本体系，不新增或覆盖正式版本标签。

## 变更说明

- M1：后台按当前机器人和群/私聊浏览持久档案，支持快照分页、有界搜索、来源定位和前后事件核对。
- M2：Agent 可查询当前会话历史与托管记忆并精确读取；后台支持记忆录入、修订、启停、版本比较/恢复及旧文件显式归属迁移。
- M3：当前机器人与会话内串行执行任务，保存阶段、结果、查询与上下文摘要；后台支持分页筛选、单条核对及等待在途操作结束后的停止，重启不重放任务。
- 补齐 Agent 动作输出、图片输入和模型响应的已有容量限制；GPT/普通聊天成功解码后继续读取 HTTP 至 EOF，修复成功回复被统计为 incomplete 的问题。

## 验证结果

上传前从公开清单生成独立源码副本，按标准流程先生成注册文件，完整统一复验的 10 步、119 项 Agent 浏览器回归、相关 Go 回归与静态检查、最终构建和 145 项隔离整机分项检查及总判定通过。排除 VCS 元数据后，副本与工作区对照构建摘要一致。模拟模型与 OneBot 验证独立于日常服务，不计为真实 QQ 验收。

真实模型七组用例通过，覆盖 GPT、普通聊天、Agent 发送/记忆保存、历史与记忆搜索/读取、识图；17 次 HTTP 传输完成，incomplete=0、failed=0。

主人私聊真实复验核对五条入站及对应回复、三项已完成 Agent 任务，无普通聊天兜底。两条旧记忆经明确授权迁移，原件与备份保留；重启后真实 Agent 保存去重、搜索、精确读取及平台回复通过，配置和 OneBot 登录保持。

可复用复验步骤见[统一入口](agent-integration-test.md#统一复验)、[真实模型测试](real-model-test.md)及[真实 QQ 验证](real-agent-acceptance.md)；详细范围见[测试摘要](self-test.md)。原始运行证据和真实身份仅保留本机。

## 使用与兼容性

从源码构建后只需重启 ZeroBot；先备份配置、档案数据库和整个 agent 目录，保留可能存在的 WAL/SHM。程序不自动迁移旧记忆、不自动修改模型密钥或人物设定；旧文件的归属须由所有者确认，迁移后按机器人分别管理。后台配置备份不包含这些聊天与记忆数据。

入口为后台“Agent 会话”，需要后台登录且目标机器人当前已连接。QQ 角色、会话开关及动作权限沿用现有规则；历史资料和记忆不能授予额外动作权限。具体操作见[使用指南](user-guide.md)、[记忆管理](agent-memory.md)、[任务控制](agent-tasks.md)及[运行维护](operations.md)。

## 限制与后续范围

其他角色的真人 Agent、客户端端到端体验和持续真实业务负载按使用者决定取消本轮验收，不记为通过。后台新页面已经隔离浏览器验证，但未使用日常后台凭据完成真人页面操作。其他操作系统没有本轮完整验收。

多模型路由、联网、定时自主动作、向量库、多 Agent 编排、旧格式导出及物理清理不属于本阶段；没有剩余的本阶段待开发功能。源码交付排除本机配置、登录状态、数据库、日志、截图和对话原始记录；本地依赖补丁及许可证随实现完整提供。
