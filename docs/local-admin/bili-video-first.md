# B站视频基础信息优先返回

本批候选在视频标题、封面和链接准备好后先发送基础消息。当前会话开启视频总结时，再获取并单独发送总结；总结失败或暂无内容时单独提示，不撤回或重复发送基础消息。第二条消息带视频链接，便于区分同时解析的视频。

入口仍为发送已有支持的B站视频链接。继续遵守会话响应、bilibiliparse服务及链接解析开关、原限速。视频总结继续用原“开启视频总结 / 关闭视频总结”命令及权限，不新增网页或开关；重启部署候选后生效。

总结请求使用B站返回内容，不调用本地或付费AI，不重新下载视频。总结HTTP请求最长12秒，响应正文最多2MiB，不自动重试，也不跟随携带Cookie的重定向。WBI签名仍复用原依赖，签名键获取不计入这12秒；该过程发生在基础消息发送之后。基础信息本身的上游读取和QQ投递仍可能失败，本批不承诺整条解析固定时长。

基础消息发送接口未确认成功时不继续请求总结。总结开关关闭时只发送基础消息；总结开启但Cookie缺失、上游业务失败或无总结时，保留真实失败/不可用状态。原业务码-1样本的成功总结仍需有效样本验收，不能由本批改进推断该问题已修复。
