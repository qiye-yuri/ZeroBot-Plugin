## 3. 候选保留：最小使用流程

1. 主人在后台 AI 设置中填写搜索服务凭据，保存后显示配置是否齐全。保存配置本身不调用外部服务。
2. 选中机器人及群/私聊，明确开启联网搜索并设置允许角色。初始仅允许主人；放开其他角色须显式修改。
3. 该会话的新 Agent 任务获得搜索工具说明。未启用或角色不允许时不提供该工具，执行边界仍核对权限。
4. Agent 提交查询，宿主执行一次搜索，将结构化结果放回同一任务上下文。Agent 回答时引用返回的来源链接。
5. 空结果、额度用尽或请求失败时，回复应说明未取得资料；不得把模型已有知识表述为刚刚搜索的结果。

普通聊天、严格 GPT 和群总结不在首批接入范围。搜索结果不会自动保存为长期记忆；模型若提出保存或发送动作，继续经过原有动作权限与执行流程。

## 4. 候选保留：配置、数据与生效规则

以下字段为建议契约，实际名称在实现时与配置仓库一致，不能据此调用当前 API。

| 对象 | 最小内容 | 存储与生效 |
| --- | --- | --- |
| 全局搜索配置 | 启用状态、提供商标识、凭据 | 放入现有控制配置；凭据按现有密钥约定只写不回显 |
| 会话搜索策略 | 机器人 ID、现有群/私聊会话键、启用状态、允许角色 | 复用控制配置，缺失即关闭；不能只以群号作为键 |
| 任务搜索状态 | 已尝试次数、成功/空结果/失败次数 | 与既有任务摘要一起保存，不建立独立事件库 |
| 搜索结果 | 本次结果编号、标题、URL、摘要 | 留在当前任务上下文；不另存响应原文或抓取网页 |

旧配置没有搜索字段时行为完全保持，不在读取时改写数据库。首次保存沿用备份和修订冲突检查；新字段与策略一次提交。密钥留空保留，清除使用现有明确操作。

任务开始捕获配置与策略；设置变更沿用当前设置代次与旧任务停止规则，不另建热更新系统。旧任务停止后不执行新搜索；在途请求若无法立即取消，返回时先检查任务状态，再决定是否接纳结果。界面与使用文档必须说明实际停止语义。

恢复方式：在新程序中通过现有备份预览/恢复迁移前控制数据库，再停机换回旧程序并核对。禁用搜索是功能回退，恢复数据库是数据回退，两者记录清楚。具体操作沿用[维护说明](operations.md)。

## 5. 候选保留：工具契约与请求链路

建议动作名 `search_web`，参数只有必填 `query`。返回示意：

```json
{
  "status": "ok",
  "results": [
    {"id": 1, "title": "示例资料", "url": "https://example.com/reference", "snippet": "资料摘要"}
  ]
}
```

结果编号只用于本次响应内对应，最终回答使用 URL，不虚构发布日期或网页全文。`empty` 表示成功但无匹配；预期搜索失败返回简短工具错误，让模型能够说明资料不可用；取消、配置代次变化及原有执行错误沿用既有终止机制。不得把失败转换成成功空列表。

首版建议固定每任务最多 2 次搜索、每次最多 5 条结果、每次 10 秒期限、响应体最多 256 KiB、总摘要最多 8,000 UTF-8 字节；这些是待提供商核对的初值，N3-01 锁定后记录最终值。它们用于控制外部请求成本与上下文大小，不新增用户可调的通用限流面板。

权限与参数校验通过后、发起请求前消耗一次额度；网络失败也计入，防止失败循环造成额外费用。搜索额度独立于原历史/记忆的三次共享查询额度。首版不自动重试，也不缓存或切换服务商。

外部文本标明为搜索资料，不能覆盖系统指令或动作权限。查询仅取显式参数；对返回链接只接受可展示的 HTTP(S) 链接，不由服务器访问它。对非法链接项按提供商解析规则明确舍弃；整份响应格式错误按失败处理。原有发送、记忆写入权限保持独立。

## 8. 候选保留：验收矩阵

| 编号 | 场景 | 必须观察的结果 | 验证方式 |
| --- | --- | --- | --- |
| S01 | 旧配置、关闭搜索、未授权角色 | 不发出搜索 HTTP；原聊天/Agent 流程保持 | Go + 隔离整机 |
| S02 | 两机器人同号群与群/私聊 | 策略与调用额度互不串用 | Go |
| S03 | 正常查询、空结果、中文查询 | 实际请求仅含预期参数，结果与 URL 对应 | 模拟 HTTP + 整机 |
| S04 | 认证失败、超时、非法/超大响应 | 明确失败，无自动重试、无凭据回显 | 模拟 HTTP |
| S05 | 第三次查询、模型重复搜索 | 无额外外部请求；原历史/记忆额度独立 | Go + 整机 |
| S06 | 搜索等待中停止或更改配置 | 返回后不再继续动作，不向其他任务注入结果 | Go + 整机 |
| S07 | 摘要含伪造权限/系统指令 | 原动作授权仍有效，无未授权平台调用 | 模拟恶意结果 + 权限回归 |
| S08 | 页面保存、撤销、修订冲突、切会话 | 显示实际生效范围，冲突不覆盖，密钥不回显 | API + 浏览器 |
| S09 | 保存后重启、备份恢复、禁用 | 策略持久化，恢复后状态一致，禁用后新任务无工具 | 隔离整机 |
| S10 | 正常带来源回答 | URL 来自实际结果；未获得资料时如实说明 | 自动化固定模型 + 约定真实模型 |

S07 证明权限边界有效，不代表可以保证模型永不受外部文本影响。S10 的固定模型结果不能替代真实模型的引用质量。真实验证建议限定一个授权会话、一次正常查询与一次无结果查询，按事先确定的次数执行；不能因为自动化通过就声称真实 QQ 已验收。

统一回归入口（仅在功能实现后运行）：

```powershell
go generate main.go
pwsh -File scripts/test-agent.ps1 -OutputName zerobot-search-validation.exe
git diff --check
```

新增测试必须进入统一入口。验收依据当次退出码、用例断言与构建摘要，不沿用历史测试数量。失败先修复再复验相关范围，最终整机使用最终提交对应的构建。

## 9. 不过度防御性编程的实施约束

- HTTP、后台输入和工具参数在边界校验；内部传递明确类型，不重复解析、判空或复制配置。
- 保留实际需要的权限、会话隔离、凭据保护、请求期限和结果上限；不新增泛化防护框架、异常吞并或多层回退。
- 使用已有错误、任务停止和备份流程，新增错误只为用户能够采取不同处理的情形。
- 用例围绕可见结果与真实故障，不为每个内部函数或文档变更添加镜像测试。
- 工作包退出条件满足即结束；新想法进入独立候选列表，不扩充当前发布门槛。
