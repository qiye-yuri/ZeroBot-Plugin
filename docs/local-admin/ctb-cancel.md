# FTB运行中任务取消

主人发送 **FTB取消** 请求停止当前FTB查询或下载。群里需@机器人，且只能取消从本群发起的任务；主人私聊可取消本实例当前FTB查询/下载。普通成员和群管理员不能取消。继续遵守机器人响应和ctb插件开关，不新增后台按钮。

“已请求取消”表示请求已提交，不代表任务已经退出。原任务结束后会向原会话报告“任务已取消”；使用FTB工具状态确认忙碌已解除，再开始新任务。取消信号绑定当前任务上下文，旧任务结束清理不会取消后来任务；每条新命令仍针对它执行时的当前任务。

取消复用原进程上下文，执行中的FTB子进程会被请求停止；ZIP校验和本地文件读写不能被立即打断，会在当前处理步骤返回后检查取消，不继续发送下载结果。直到任务真正结束才释放忙碌锁。没有运行中的查询/下载时会明确提示。

已经进入QQ上传、或正在执行FTB重发的任务不在本命令范围内，不能保证撤回平台已接收的文件。已下载的部分文件保留，不自动删除；已扣群下载次数不退还，避免以取消绕过下载额度。没有新增任务历史、自动重试或后台管理框架。

部署后命令生效，无需改配置；取消本身不依赖重新读取FTB配置。任务已开始后即使配置文件暂时不可读，主人仍可请求停止。其他群不能停止当前群任务，需在来源群或主人私聊操作。

开发、验证和集中QQ状态见[本批计划及验收](ctb-cancel-acceptance.md)。本页为候选使用说明，生效以部署记录为准。
