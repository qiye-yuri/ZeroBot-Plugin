# AI中心与群互动

P104 `aichat` 是统一AI入口。原P054 `llm` 和P103 `aichatcfg` 已并入，不再作为独立插件出现在后台、QQ服务列表或导出列表中；原模型配置、会话参数及指令保留。内部继续使用原参数存储，避免重置历史设置。旧llm和aichatcfg的独立启停状态不再决定响应，统一由aichat开关决定。

## 如何触发

| 操作 | 行为与权限 |
| --- | --- |
| 私聊发送一段文字 | 自然聊天；配置好Agent时可调用其工具，否则走普通聊天 |
| 群内@机器人并发送文字 | 自然聊天／Agent；受“响应AT”设置影响 |
| `/gpt 你的问题` | 明确调用GPT模型；不受自然聊天随机触发概率影响 |
| 引用一条消息，再发送`/gpt 请解释引用内容` | 将引用原文与当前指令分别交给GPT模型 |
| `群聊总结 10` | 总结最近消息，仅群聊，要求群管理员或机器人主人 |
| `查看AI聊天配置` | 主人查看配置；敏感内容保持脱敏 |
| 后台“AI设置” | 管理模型、接口、人物设定及会话参数 |

自然聊天需要模型就绪、当前会话允许响应且aichat启用。群中没有@时按配置概率触发；概率0表示不随机插话。纯@且没有文字不触发原来的固定台词。响应AT关闭时定向自然聊天可能不响应，可使用明确的`/gpt`命令。GPT与总结继续使用各自模型路由及原GPT温度参数；配置表单保留这些区别。GPT／总结沿用每会话30秒请求限额。

需要Agent工具时，以自然语言说明具体任务，例如“请检索本会话历史，找出刚才的测试代号”。能否执行取决于Agent配置、权限和工具可用性；`/gpt`是普通问答入口，不等同于Agent工具执行。

`/启用 aichat`、`/禁用 aichat`控制统一入口，包括GPT、群聊总结及聊天配置命令。关闭后可通过后台或服务控制命令重新开启。服务控制沿用原权限，群内建议@机器人操作。修改模型密钥、接口等敏感配置仍限主人私聊。无需重新填写原有配置。

## 按间隔主动接话与相关续聊

在后台“AI设置”选择群号，勾选“主动接话”，设置间隔与续聊窗口后保存。也可以由群管理员或机器人主人在群中发送：

| 命令 | 作用 |
| --- | --- |
| `开启AI主动接话` | 开启当前群的新接话模式 |
| `关闭AI主动接话` | 关闭当前群的新模式，恢复原来的非@概率设置 |
| `设置AI主动接话间隔10` | 最小接话间隔10分钟；支持1～1440分钟 |
| `设置AI续聊窗口2` | 机器人回复后的相关话题窗口2分钟；支持1～30分钟 |
| `查看AI聊天配置` | 主人查看当前配置 |

新功能默认关闭，间隔默认10分钟，续聊窗口默认2分钟。开启后替代该群的“非@消息触发概率”，不叠加两种自动触发方式。首次收到可处理的新消息开始计时；间隔到达后，在下一条可处理的新消息上主动接话。没有新消息不会自行发言。成功回复会重新计算间隔；请求失败也遵守间隔，避免连续重试刷屏。重启后计时与短期话题状态重新开始，保存的设置保留。

开启此模式时，@机器人或文字包含至少两个字的完整机器人昵称会直接触发，不受间隔、相关性判定或旧“响应@”选项限制；忙碌时会提示稍后重试。仍遵守AI插件开关、群沉默、黑名单与已有权限。机器人自身发送的消息不会触发回复，不因回复里包含自己的昵称而循环响应。

成功向当前群发送文字或AI语音后，窗口内的新消息由聊天模型判断是否直接延续最近的机器人对话。相关时继续回复并更新窗口，无关、无法判断或判断失败时保持安静。同一机器人、同一群的相关性检查最多每5秒一次；新的成功回复允许马上判断下一条跟进消息。判断需要额外调用已配置的聊天模型，不执行工具，不能保证语义判断完全准确。明确提及机器人可直接发起对话。

此功能仅用于群聊。不同机器人账号、不同群的计时及话题状态互相隔离；私聊和`/gpt`入口保持原行为。
