# 查弹幕：头像不可用时保留记录

入口仍为“查弹幕 用户UID或名字 [页码]”，用户名/UID选择、群私聊权限、服务开关和数据来源不变。弹幕记录接口成功且返回非空记录后，头像作为可选显示内容处理。

用户头像或某个主播头像读取失败、超时、返回坏图或超过限制时，该位置显示“头像暂不可用”，继续展示已经取得的记录。每个位置独立加载，不能沿用上一人头像；支持按真实图片内容解码WebP，不再单凭文件名跳过。

整页头像网络读取共用最多3秒，仍受原查询上下文剩余时间限制；预算耗尽后后续头像直接占位，不逐个额外等待。不自动重试、不携带B站Cookie、不创建新的磁盘头像缓存。单个头像响应最多2MiB，解码尺寸最多2048×2048，过大或非图片占位。

本功能不解决第三方弹幕记录接口自身超时或未收录；记录获取失败仍报错，没有记录仍明确提示，不能生成虚假的空报告。用户资料不可用仍按原规则标注未知。字体、渲染、磁盘或QQ图片发送本身失败也不等同于头像故障，本批不承诺全部出图故障都能恢复。

部署新候选后生效，无新开关或后台页面。具体测试、部署与QQ集中验收见[本批记录](danmaku-avatar-acceptance.md)。
